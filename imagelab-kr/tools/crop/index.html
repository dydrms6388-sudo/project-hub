사진 자르기 소개

사진 자르기(크롭) 도구는 사진에서 필요한 부분만 남기고 잘라냅니다. 자유 비율은 물론 1:1(정사각), 4:3, 16:9 같은 비율 프리셋을 지원해 SNS 게시물·썸네일 규격에 맞추기 좋고, 프로필 사진용 원형 크롭도 제공합니다.

선택 영역은 드래그로 이동하고 모서리·변의 핸들로 크기를 조절합니다. 빈 곳을 드래그하면 새 영역을 그릴 수 있습니다. 잘라낸 결과는 원본 해상도 그대로 무손실 PNG로 저장되며, 원형 크롭은 바깥 영역이 투명하게 처리됩니다.

사용법

  1. 사진 1장 선택
  2. 비율 프리셋 선택 (자유/1:1/16:9/원형 등)
  3. 드래그로 영역 이동, 핸들로 크기 조절
  4. 「잘라서 다운로드」 클릭

자주 묻는 질문

원형으로 자르면 바깥은 어떻게 되나요?

PNG의 투명 영역으로 저장됩니다. 투명을 지원하지 않는 곳에 올리면 검정 또는 흰색으로 보일 수 있으니, 그 경우 「이미지 변환」에서 JPG로 바꾸면 흰 배경이 채워집니다.

화질이 떨어지나요?

아니요. 선택한 영역을 원본 해상도 그대로 잘라 무손실 PNG로 저장하므로 화질 손실이 없습니다.

모바일에서도 사용할 수 있나요?

네. 터치 드래그로 영역 이동과 크기 조절이 가능합니다. 다만 세밀한 조절은 PC가 더 편합니다.
