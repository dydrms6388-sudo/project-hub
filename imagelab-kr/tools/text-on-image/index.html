사진에 글씨 넣기

외곽선·그림자 효과가 있는 텍스트를 드래그로 원하는 위치에 얹습니다. 여러 개 추가 가능.

🔒 모든 처리는 이 브라우저 안에서만 이루어집니다. 사진·파일이 서버로 전송되지 않습니다.
이미지를 선택하거나 여기에 끌어다 놓으세요 클릭하여 파일 선택 · 사진은 서버로 전송되지 않습니다

미리보기에서 텍스트를 드래그해 위치를 옮기고, 클릭해서 선택하세요.

사진에 글씨 넣기 소개

사진에 글씨 넣기 도구는 사진 위에 텍스트를 얹어 짤·안내 이미지·간단한 썸네일을 만듭니다. 어떤 배경에서도 잘 읽히도록 외곽선(테두리)과 그림자 효과를 지원하며, 글꼴은 오픈 라이선스 한글 웹폰트인 Pretendard와 시스템 고딕·명조 등을 선택할 수 있습니다.

텍스트는 여러 개 추가할 수 있고, 미리보기 화면에서 드래그해 원하는 위치에 배치합니다. 줄바꿈도 지원하므로 위·아래 두 줄 밈 스타일도 텍스트 하나로 만들 수 있습니다. 저장은 원본 해상도 기준 PNG/JPG로 이루어집니다.

사용법

  1. 사진 1장 선택
  2. 내용 입력, 글꼴·크기·색·외곽선·그림자 설정
  3. 미리보기에서 드래그로 위치 이동, 필요하면 「텍스트 추가」
  4. PNG 또는 JPG 저장

자주 묻는 질문

글꼴을 더 추가할 수 없나요?

저작권 문제 없이 웹에서 쓸 수 있는 오픈 라이선스 글꼴(Pretendard)과 기기에 내장된 시스템 글꼴만 제공합니다. 기기에 설치된 글꼴은 시스템 고딕/명조 선택 시 자동 반영됩니다.

외곽선이 깨져 보여요.

외곽선 두께를 글자 크기에 비해 너무 크게 하면 획이 겹쳐 보일 수 있습니다. 두께를 줄이거나 글자 크기를 키워 보세요.

미리보기와 저장 결과가 다른가요?

미리보기는 화면 크기에 맞게 축소 표시될 뿐, 저장은 항상 원본 해상도로 렌더링됩니다. 위치·비율은 동일하게 유지됩니다.
