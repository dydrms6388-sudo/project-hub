배경 제거 실험적 · PC 권장

AI 모델을 브라우저에 내려받아 기기 안에서 배경을 지웁니다. 사진은 어디에도 전송되지 않습니다.

🔒 모든 처리는 이 브라우저 안에서만 이루어집니다. 사진·파일이 서버로 전송되지 않습니다.

실험적 기능 · PC 권장 — 최초 사용 시 AI 모델(약 40MB)을 내려받으며(이후 캐시), 기기 성능에 따라 수 초~수십 초가 걸립니다. 모바일이나 사양이 낮은 기기에서는 실패할 수 있습니다.

이미지를 선택하거나 여기에 끌어다 놓으세요 클릭하여 파일 선택 · 사진은 서버로 전송되지 않습니다

배경 제거 소개

배경 제거 도구는 AI 분할 모델(RMBG-1.4)을 이용해 사진에서 피사체만 남기고 배경을 지웁니다. 보통 이런 기능은 사진을 서버에 올려 처리하지만, 이 도구는 모델 자체를 브라우저에 내려받아 사용자의 기기 안에서 추론합니다. 그래서 사진이 외부로 전송되지 않습니다.

배경을 지운 뒤에는 투명 PNG로 저장하거나, 단색·그라데이션 배경으로 바꿔 증명사진 스타일·상품 사진 스타일을 만들 수 있습니다. 최초 1회 모델 다운로드(약 40MB) 후에는 브라우저 캐시를 사용해 더 빠르게 시작됩니다.

AI 결과물은 완벽하지 않을 수 있습니다. 머리카락·유리처럼 경계가 복잡한 부분은 어색하게 잘릴 수 있으니 참고용으로 활용하세요.

사용법

  1. 사진 1장 선택
  2. 「배경 제거 시작」 클릭 — 최초 1회 모델 다운로드 진행률 표시
  3. 완료 후 투명/단색/그라데이션 배경 선택
  4. PNG로 저장

자주 묻는 질문

정말 사진이 서버로 안 가나요?

네. AI 모델 파일을 내려받는 통신만 발생하고, 사진 데이터는 브라우저 밖으로 나가지 않습니다. 비행기 모드에서도 모델이 캐시되어 있으면 동작합니다.

실패하거나 너무 느려요.

모델 로딩에는 안정적인 인터넷이, 추론에는 어느 정도의 메모리·연산 성능이 필요합니다. PC(노트북 이상)의 최신 크롬·엣지 브라우저를 권장하며, 이미지가 매우 크면 자동으로 축소해 처리합니다.

경계가 지저분하게 잘렸어요.

머리카락·반투명 물체·배경과 색이 비슷한 옷 등은 AI가 어려워하는 영역입니다. 대비가 뚜렷한 사진일수록 결과가 좋습니다.
