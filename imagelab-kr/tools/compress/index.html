사진 용량 줄이기

품질을 직접 고르거나 목표 용량(KB)을 지정하면 알아서 맞춰 드립니다. 여러 장 일괄 처리 가능.

🔒 모든 처리는 이 브라우저 안에서만 이루어집니다. 사진·파일이 서버로 전송되지 않습니다.
이미지 여러 장을 선택하거나 끌어다 놓으세요 클릭하여 파일 선택 (여러 장 가능) · 사진은 서버로 전송되지 않습니다

    지정한 용량 이하가 되도록 품질을 자동 탐색하고, 부족하면 해상도를 단계적으로 줄입니다.

      전/후 비교 (첫 번째 사진)

      가운데 손잡이를 좌우로 움직여 원본과 압축본을 비교하세요.

      사진 용량 줄이기 소개

      사진 용량 줄이기는 카카오톡·이메일 첨부, 게시판 업로드 용량 제한, 홈페이지 로딩 속도 개선 등 일상에서 가장 자주 필요한 이미지 작업입니다. 이 도구는 프로그램 설치 없이 브라우저 안에서 JPG 또는 WEBP 형식으로 사진을 압축하며, 사진이 서버로 전송되지 않아 개인 사진도 안심하고 사용할 수 있습니다.

      품질(%)을 직접 지정하는 방식과 목표 용량(KB)을 지정하는 방식을 모두 지원합니다. 목표 용량 모드에서는 품질 값을 이진 탐색으로 자동 조절해 지정한 용량 이하로 맞추고, 최저 품질로도 부족하면 해상도를 단계적으로 줄여 목표를 달성합니다. 여러 장을 한 번에 올리면 일괄 압축 후 ZIP으로 받을 수 있습니다.

      사용법

      1. 사진을 여러 장 선택하거나 끌어다 놓기
      2. 품질 직접 지정 또는 목표 용량(KB) 지정 선택
      3. JPG/WEBP 형식 선택 후 「압축하기」 클릭
      4. 전/후 비교 슬라이더로 화질 확인 후 개별 다운로드 또는 전체 ZIP 저장

      자주 묻는 질문

      압축하면 화질이 얼마나 나빠지나요?

      JPG·WEBP는 손실 압축이라 품질을 낮출수록 세밀한 부분이 뭉개집니다. 다만 품질 70~85% 구간은 용량이 크게 줄면서도 화면으로는 차이를 느끼기 어려운 경우가 많습니다. 전/후 비교 슬라이더로 직접 확인해 보세요.

      압축한 사진의 화질을 원본으로 되돌릴 수 있나요?

      아니요. 손실 압축으로 버려진 정보는 복구할 수 없습니다. 원본 파일은 삭제하지 말고 따로 보관하는 것을 권장합니다.

      사진이 서버에 업로드되나요?

      아니요. 모든 압축은 사용자의 브라우저(기기) 안에서만 처리되며, 사진이 외부로 전송되지 않습니다.

      PNG로도 저장할 수 있나요?

      PNG는 무손실 형식이라 품질 조절로 용량을 줄이기 어렵습니다. 용량 절감이 목적이라면 JPG 또는 WEBP를 권장하며, 형식만 바꾸려면 「이미지 변환」 도구를 이용하세요.
