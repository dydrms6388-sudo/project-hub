이미지 크기 조절

픽셀 직접 입력, 퍼센트, 자주 쓰는 프리셋(카톡 프로필·인스타·유튜브 썸네일)으로 크기를 바꿉니다.

🔒 모든 처리는 이 브라우저 안에서만 이루어집니다. 사진·파일이 서버로 전송되지 않습니다.
이미지를 선택하거나 여기에 끌어다 놓으세요 클릭하여 파일 선택 · 사진은 서버로 전송되지 않습니다

프리셋 크기와 비율이 다르면 중앙 기준으로 잘라 맞춥니다.

이미지 크기 조절 소개

이미지 크기 조절 도구는 사진의 가로·세로 픽셀을 원하는 값으로 바꿔 줍니다. 픽셀을 직접 입력하는 기본 모드 외에, 퍼센트로 축소·확대하는 모드와 카톡 프로필(640×640)·인스타그램 게시물(1080×1080)·유튜브 썸네일(1280×720) 같은 자주 쓰는 용도의 프리셋 모드를 제공합니다.

비율 유지 옵션을 켜면 한쪽 값만 입력해도 나머지가 자동 계산되어 사진이 찌그러지지 않습니다. 프리셋처럼 비율이 다른 크기를 선택하면 중앙 기준으로 잘라(cover) 정확한 크기로 맞춥니다. 처리 결과는 미리보기로 즉시 확인할 수 있습니다.

사용법

  1. 사진 1장을 선택
  2. 픽셀/퍼센트/프리셋 중 원하는 모드 선택
  3. 값을 입력하면 미리보기가 즉시 갱신됨
  4. 「다운로드」로 저장 (원본 형식 유지)

자주 묻는 질문

작은 사진을 크게 키우면 화질이 좋아지나요?

단순 확대는 픽셀을 늘려 그릴 뿐 없는 정보를 만들지 못하므로 흐릿해집니다. 화질 개선이 목적이라면 「사진 화질 좋게 하기(AI 업스케일)」 도구를 사용해 보세요. 다만 그것도 원본에 없는 세부를 추정으로 채우는 것입니다.

비율이 다른 프리셋을 선택하면 사진이 찌그러지나요?

아니요. 중앙을 기준으로 잘라내는 방식(cover)으로 맞추기 때문에 비율이 왜곡되지 않습니다. 잘리는 위치를 직접 고르고 싶다면 「사진 자르기」 도구를 먼저 사용하세요.

어떤 형식으로 저장되나요?

원본이 PNG면 PNG, WEBP면 WEBP, 그 외에는 JPG로 저장됩니다. 파일명은 원본이름-resized-크기 형태입니다.
