    GIF 만들기 소개

    GIF 만들기 도구는 사진·이미지 여러 장을 순서대로 이어 움직이는 GIF(움짤)를 만듭니다. 프레임 간격(밀리초)을 조절해 빠르게 넘어가는 애니메이션도, 천천히 바뀌는 슬라이드쇼도 만들 수 있습니다.

    프레임 크기가 서로 달라도 첫 번째 이미지 비율에 맞춰 자동 배치되며 남는 부분은 지정한 여백 색으로 채워집니다. GIF는 256색 제한이 있는 형식이라 사진에서는 색 띠가 생길 수 있고, 용량이 커질 수 있으니 최대 너비를 480px 정도로 유지하는 것을 권장합니다. 인코딩은 gif.js 라이브러리로 브라우저 안에서 처리됩니다.

    사용법

    1. 이미지 2장 이상 선택
    2. ↑↓로 순서 조정, 프레임 간격(ms)과 최대 너비 설정
    3. 「GIF 만들기」 클릭 후 인코딩 완료 대기
    4. 미리보기 확인 후 다운로드

    자주 묻는 질문

    프레임 간격은 어느 정도가 좋나요?

    슬라이드쇼 느낌은 500~1000ms, 자연스러운 애니메이션은 60~120ms가 적당합니다. 30ms 미만은 브라우저·플랫폼에서 무시될 수 있어 최소 30ms로 제한됩니다.

    GIF 화질이 원본보다 나빠 보여요.

    GIF는 프레임당 최대 256색만 표현하는 오래된 형식이라 사진처럼 색이 풍부한 이미지는 계단 현상이 생깁니다. 화질이 중요하면 프레임 수를 줄이거나 그림·스크린샷 위주로 사용하세요.

    동영상을 GIF로 바꿀 수 있나요?

    이 도구는 이미지→GIF 전용입니다. 동영상에서 장면을 캡처한 뒤 캡처 이미지를 올리는 방식으로 활용할 수 있습니다.
