🔒 모든 처리는 이 브라우저 안에서만 이루어집니다. 사진·파일이 서버로 전송되지 않습니다.
로고·아이콘 이미지를 선택하세요 (정사각 권장) 클릭하여 파일 선택 · 사진은 서버로 전송되지 않습니다

정사각형이 아닌 이미지입니다. 아래 맞춤 방식에 따라 잘리거나 여백이 생깁니다.

파비콘 만들기 소개


파비콘(favicon)은 브라우저 탭·즐겨찾기·홈 화면에 표시되는 사이트 아이콘입니다. 요즘은 용도별로 여러 크기가 필요합니다: 탭용 16/32px, 구형 브라우저용 favicon.ico, 아이폰 홈 화면용 180px(apple-touch-icon), 안드로이드용 192/512px 등입니다.


이 도구는 이미지 한 장으로 위 크기를 모두 만들어 ZIP 하나로 묶어 줍니다. favicon.ico는 16·32·48px PNG를 담은 표준 ICO 컨테이너로 조립되며, ZIP에는 붙여넣기만 하면 되는 HTML 코드가 담긴 README도 포함됩니다. ZIP 조립까지 전부 브라우저 안에서 처리됩니다.


사용법


    

  1. 로고·아이콘 이미지 선택 (512px 이상 정사각 권장)
    2. 

  2. 맞춤 방식(채우기/전체 보이기)과 배경 선택
    3. 

  3. 「ZIP 생성·다운로드」 클릭
    4. 

  4. 압축을 풀어 사이트 루트에 올리고, HTML 코드를 에 추가
    5. 



자주 묻는 질문


어떤 이미지를 올리는 게 좋나요?
512×512px 이상의 정사각 이미지를 권장합니다. 16px까지 줄었을 때도 알아볼 수 있도록 단순한 도형·글자 위주의 디자인이 좋습니다.


favicon.ico는 왜 따로 필요한가요?
오래된 브라우저와 일부 시스템은 /favicon.ico 경로를 직접 찾습니다. 이 도구의 ico 파일은 16·32·48px을 한 파일에 담은 표준 형식이라 호환성이 좋습니다.


만든 파비콘이 사이트에 바로 안 보여요.
브라우저가 파비콘을 강하게 캐시하기 때문입니다. 새 탭이나 시크릿 창에서 확인하거나 캐시를 비운 뒤 새로고침해 보세요.
