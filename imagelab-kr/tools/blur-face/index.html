얼굴 모자이크

가릴 부분을 붓으로 문지르면 모자이크(또는 블러) 처리됩니다. 얼굴·개인정보 가리기에 알맞습니다.

🔒 모든 처리는 이 브라우저 안에서만 이루어집니다. 사진·파일이 서버로 전송되지 않습니다.
이미지를 선택하거나 여기에 끌어다 놓으세요 클릭하여 파일 선택 · 사진은 서버로 전송되지 않습니다

가리고 싶은 부분을 마우스/손가락으로 문지르세요.

얼굴 모자이크 소개

얼굴 모자이크 도구는 사진 속 얼굴이나 개인정보를 붓으로 문질러 가립니다. 사각형 영역보다 자연스럽게, 필요한 부분만 정확히 가릴 수 있는 브러시 방식으로, 모자이크와 블러(흐림) 두 가지 효과를 지원합니다.

브러시 크기와 효과 강도를 슬라이더로 조절할 수 있고, 실수한 획은 실행 취소로 되돌립니다. 모든 처리는 브라우저 안에서만 이루어져 민감한 사진도 외부로 전송되지 않으며, 저장된 결과물에는 가려진 부분의 원본 정보가 남지 않습니다.

자동 얼굴 인식 없이 손으로 직접 문지르는 방식이라 어떤 사진에서도 확실하게 동작합니다. 인식 오류로 얼굴이 안 가려지는 사고가 없습니다.

사용법

  1. 사진 1장 선택
  2. 모자이크/블러 선택, 브러시 크기·강도 조절
  3. 가릴 부분을 문지르기 (여러 곳 가능)
  4. PNG 또는 JPG로 저장

자주 묻는 질문

얼굴을 자동으로 찾아 주지는 않나요?

이 도구는 수동 브러시 방식입니다. 자동 인식은 놓치는 얼굴이 생길 수 있는 반면, 직접 문지르는 방식은 가릴 대상을 빠뜨릴 위험이 없고 얼굴 외에 이름표·번호판 등도 자유롭게 가릴 수 있습니다.

모자이크와 블러 중 뭐가 더 안전한가요?

개인정보 보호 목적이라면 모자이크를 강도 높게 쓰는 것이 좋습니다. 약한 블러는 복원 시도에 상대적으로 취약할 수 있습니다. 두 효과 모두 저장 파일에는 원본 픽셀이 포함되지 않습니다.

문지른 부분을 일부만 되돌릴 수 있나요?

「실행 취소」로 최근 획 단위(12단계)로 되돌릴 수 있고, 「모두 지우기」로 전체를 초기화할 수 있습니다.
