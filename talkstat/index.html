TalkStat가 지키는 원칙

첫째, 대화는 브라우저 밖으로 나가지 않습니다. TalkStat의 모든 페이지는 정적 파일로만 구성되어 있고, 업로드한 파일은 브라우저 메모리에서만 읽혀 Web Worker 안에서 분석됩니다. 네트워크 요청이 발생하지 않으므로 개발자 도구로 직접 검증할 수 있습니다. 새로고침하면 파일 내용은 사라지고, 결과 저장을 원할 때만 요약 통계가 내 기기의 localStorage에 남습니다.

둘째, 사실 지표만 보여줍니다. 메시지 수, 답장 시간, 시간대 분포 같은 계산 가능한 수치만 제공하며, 대화 습관으로 성격이나 관계를 단정하는 해석은 제공하지 않습니다. 수치는 재미로 보는 참고 자료로 활용해 주세요.

셋째, 세 가지 내보내기 형식을 모두 지원합니다. 안드로이드 txt, 아이폰 txt, PC 카카오톡 txt/csv 형식을 자동 감지하고, 여러 줄 메시지 병합과 입장·퇴장·사진·이모티콘·삭제된 메시지 분류까지 처리합니다.
