카톡 대화 분석기는 이런 도구예요

TalkStat 카톡 대화 분석은 카카오톡의 "대화 내보내기" 기능으로 저장한 텍스트 파일을 읽어, 두 사람(또는 단체방)의 대화 패턴을 숫자로 보여주는 무료 도구입니다. 누가 메시지를 더 많이 보내는지, 답장은 평균 몇 분 만에 오는지, 대화가 가장 활발한 요일과 시간대는 언제인지 같은 궁금증을 데이터로 확인할 수 있습니다.

가장 중요한 특징은 개인정보 처리 방식입니다. 파일은 업로드되지 않고 브라우저 메모리에서만 읽히며, 분석 계산도 브라우저 안의 Web Worker에서 실행됩니다. 네트워크 요청이 발생하지 않으므로 대화 내용이 외부로 나갈 경로 자체가 없고, 새로고침하면 파일 내용은 즉시 사라집니다.

분석 결과에는 참여자별 메시지·글자·사진·이모티콘 수, 시간대×요일 히트맵, 월별 추이, 평균 답장 시간, 먼저 말 건 비율, 가장 긴 침묵 구간, 자주 쓴 단어와 이모지, 대화 골든타임이 포함됩니다. 결과는 사실 그대로의 수치이며, 성격이나 관계를 단정하는 해석은 제공하지 않습니다.

사용법

  1. 카카오톡에서 분석할 대화방의 대화를 내보냅니다. 방법은 카카오톡 대화 내보내기 방법을 참고하세요.
  2. 저장된 .txt 또는 .csv 파일을 위 업로드 영역에 끌어다 놓거나 눌러서 선택합니다.
  3. 형식은 자동으로 감지됩니다. 감지가 잘못되면 형식을 직접 선택한 뒤 다시 올려 주세요.
  4. 결과 대시보드를 확인하고, 필요하면 리포트 카드를 PNG로 저장합니다.

자주 묻는 질문

대화 내용이 정말 서버로 안 가나요?

네. 이 페이지는 정적 파일로만 구성되어 있고 분석 중 네트워크 요청을 보내지 않습니다. 브라우저 개발자 도구의 네트워크 탭에서 직접 확인할 수도 있습니다. 파일은 메모리에서만 처리되며 새로고침하면 사라집니다.

어떤 내보내기 형식을 지원하나요?

안드로이드 txt("2026년 8월 19일 오후 3:12, 이름 : 내용"), 아이폰 txt("2026. 8. 19. 오후 3:12, 이름 : 내용"), PC 카카오톡 txt("[이름] [오후 3:12] 내용")와 csv(Date,User,Message) 형식을 지원합니다. 입장·퇴장 안내, 사진·이모티콘·삭제된 메시지도 자동 분류되고 여러 줄 메시지도 하나로 합쳐 집계합니다.

평균 답장 시간은 어떻게 계산하나요?

발신자가 바뀌는 순간의 시간 간격을 답장으로 봅니다. 다만 밤사이 공백처럼 8시간을 넘는 간격은 답장이 아니라 "새 대화 시작"으로 분류해 평균에서 제외합니다. 평균과 함께 중앙값도 보여주므로 튀는 값의 영향을 줄여 볼 수 있습니다.

결과 저장은 어떻게 되나요?

"요약 결과 브라우저에 저장"을 누르면 집계 통계만 내 브라우저의 localStorage에 저장됩니다. 원문 메시지는 저장되지 않으며, 저장된 요약은 같은 화면에서 언제든 삭제할 수 있습니다.

대화 MBTI 같은 성격 분석도 해주나요?

아니요. 이 도구는 메시지 수·시간 같은 사실 지표만 계산합니다. 대화 습관으로 성격이나 관계를 단정하는 해석은 근거가 부족하다고 보아 제공하지 않습니다. 수치는 참고용이며 관계에 대한 판단 자료로 쓰기보다는 재미로 봐 주세요.
