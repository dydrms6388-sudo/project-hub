단어 통계로 보는 우리 대화

이 도구는 카카오톡 대화 내보내기 파일에서 텍스트 메시지만 골라 단어 빈도를 셉니다. '근데', '그냥'처럼 어느 대화에나 나오는 불용어와 한 글자 단어, 링크(URL)는 제외해서 대화방의 개성이 드러나는 단어가 위로 올라오게 했습니다.

한국어 채팅의 상징인 ㅋㅋ와 ㅎㅎ는 단어 목록에 섞으면 항상 1위를 차지하므로 별도 카운터로 분리해 참여자별로 집계합니다. 😂 같은 텍스트 이모지는 문자 단위로 빈도를 세고, 카카오톡 스티커형 이모티콘은 개수만 집계합니다.

다른 도구와 마찬가지로 파일은 서버로 전송되지 않고 브라우저 메모리에서만 처리됩니다. 집계는 Web Worker에서 실행되어 큰 파일도 화면 멈춤 없이 분석됩니다.

사용법

  1. 카카오톡 대화 내보내기 방법대로 대화를 파일로 저장합니다.
  2. 파일을 업로드 영역에 올리면 단어 구름과 TOP 20 차트가 바로 표시됩니다.
  3. 참여자별 최애 단어 표에서 서로의 말버릇을 비교해 보세요.

자주 묻는 질문

조사가 붙은 단어("밥을", "밥이")가 따로 집계돼요.

이 도구는 형태소 분석기 없이 띄어쓰기 기준으로 단어를 세기 때문에 조사가 붙은 형태가 따로 잡힐 수 있습니다. 흔한 불용어는 제거하지만 완전한 형태소 분석은 하지 않으므로 결과는 근사치로 봐 주세요.

특정 단어가 안 보여요.

한 글자 단어와 불용어 목록에 포함된 흔한 단어는 제외됩니다. 또한 사진·이모티콘·삭제된 메시지 등 텍스트가 아닌 메시지는 단어 집계에 들어가지 않습니다.

결과를 저장하거나 공유할 수 있나요?

화면을 캡처해 공유할 수 있고, 전체 분석 도구에서는 사실 지표를 담은 리포트 카드를 PNG로 저장할 수 있습니다. 별도의 서버 저장 기능은 없으며 원하는 경우에도 브라우저 localStorage에만 저장됩니다.
