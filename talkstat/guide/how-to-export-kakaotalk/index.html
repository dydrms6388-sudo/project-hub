카카오톡 대화 내보내기 방법

안드로이드·아이폰·PC별로 대화를 txt/csv 파일로 저장하는 절차를 정리했습니다. 저장한 파일은 카톡 대화 분석에 올려 브라우저 안에서만 분석할 수 있어요.

📱 안드로이드

  1. 내보낼 대화방에 들어가 오른쪽 위 메뉴(≡)를 누릅니다.
  2. 오른쪽 아래 설정(톱니바퀴) 아이콘을 누릅니다.
  3. 대화 내용 내보내기를 선택합니다.
  4. 텍스트만 보내기를 선택합니다. (모든 파일 포함을 고르면 압축 파일로 저장됩니다)
  5. 메일, 메시지 앱 또는 파일로 저장을 선택해 .txt 파일을 받습니다.

저장된 파일의 형식: 2026년 8월 19일 오후 3:12, 이름 : 내용

🍎 아이폰 (iOS)

  1. 내보낼 대화방에서 오른쪽 위 메뉴(≡)를 누릅니다.
  2. 오른쪽 아래 설정(톱니바퀴)을 누른 뒤 대화 내용 메뉴로 이동합니다.
  3. 대화 내용 저장(또는 내보내기)을 선택합니다.
  4. 공유 시트에서 파일에 저장을 고르면 .txt 파일이 저장됩니다. 메일로 나에게 보내는 방법도 편리합니다.

저장된 파일의 형식: 2026. 8. 19. 오후 3:12, 이름 : 내용

💻 PC 카카오톡 (Windows/Mac)

  1. PC 카카오톡에서 내보낼 대화방을 엽니다.
  2. 오른쪽 위 메뉴(≡) → 대화 내용 → 대화 내보내기를 선택합니다.
  3. 저장 위치를 정하면 .txt 파일로 저장됩니다. 버전에 따라 csv 저장을 지원하기도 합니다.

저장된 파일의 형식: [이름] [오후 3:12] 내용 과 날짜 구분줄, 또는 Date,User,Message 형식의 csv

내보내기 전에 알아두세요

  • 기기에 남아 있는 대화만 내보내집니다. 기기 변경·대화 삭제 이전의 내용은 포함되지 않습니다.
  • 파일에는 대화명과 메시지 내용이 그대로 담기므로 파일 보관·전달에 주의하세요.
  • TalkStat는 이 파일을 서버로 전송하지 않고 브라우저 메모리에서만 읽어 분석합니다. 분석 후 새로고침하면 내용이 사라집니다.
  • 상대방의 동의 없이 대화 내용을 외부에 공개하는 것은 삼가 주세요.

단체방도 내보낼 수 있나요?

네. 1:1 대화와 동일한 절차로 단체 대화방도 내보낼 수 있고, TalkStat는 참여자 수 제한 없이 분석합니다.

파일 용량이 큰데 분석되나요?

수만 건 규모의 대화도 브라우저 안 Web Worker에서 분석됩니다. 파일이 매우 크면 몇 초 정도 걸릴 수 있습니다.

"모든 파일 포함"으로 내보냈어요.

압축(zip) 파일이 만들어졌다면 압축을 푼 뒤 그 안의 .txt 파일만 TalkStat에 올리면 됩니다.
