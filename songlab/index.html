소개

AI 작사작곡 스튜디오는 악기를 다루지 못해도, 악보를 읽지 못해도 한 곡의 뼈대를 손에 쥘 수 있게 만든 무료 도구입니다. 화면은 두 갈래로 나뉩니다. 첫째, 설렘·이별·새벽·응원처럼 여덟 가지 감성 무드 중 하나를 고르면 그 정서에 어울리는 코드 진행과 빠르기가 정해지고, 그 위로 멜로디가 흐르고, 멜로디의 음표 수에 맞춰 음절을 센 한국어 가사가 붙습니다. 둘째, 머릿속에 맴도는 멜로디를 마이크에 대고 허밍하면 소리의 높낮이를 추적해 음표로 옮기고, 조성과 화음을 추정해 악보와 코드를 뽑아낸 뒤 그 멜로디를 주제로 삼아 벌스와 코러스를 이어 붙입니다.

모든 계산은 브라우저 안에서 끝납니다. 코드 진행을 고르는 화성 규칙, 멜로디를 짓는 모티프 전개, 가사를 맞추는 음절 계산, 허밍의 음높이를 재는 자기상관 분석, 악보를 그리는 오선 배치, 소리를 내는 신시사이저까지 전부 이 페이지 안에 들어 있어서 외부 인공지능 서버를 부르지 않고 마이크 소리도 업로드하지 않습니다. 결과가 마음에 들면 재생해 들어 보고, 표준 MIDI 파일로 내려받아 다른 음악 프로그램에서 편곡을 이어가거나, 가사·코드 시트를 통째로 복사해 연습실로 가져가세요.

이렇게 사용하세요

  1. 무드로 만들기 탭에서 감성 무드를 하나 고릅니다. 무드마다 코드 진행과 기본 빠르기가 달라집니다.
  2. 가사에 넣고 싶은 단어가 있다면 적어 주세요. 제목과 가사 곳곳에 자연스럽게 섞여 들어갑니다.
  3. 조성·곡 길이·빠르기를 취향대로 조정하고 한 곡 만들기를 누릅니다.
  4. 결과 화면에서 재생을 눌러 멜로디·코드·베이스가 함께 연주되는 소리를 확인합니다.
  5. 머릿속 멜로디가 있다면 허밍·노래로 만들기 탭에서 녹음하세요. 음정이 음표로 옮겨지고 조성과 코드가 자동으로 붙습니다.
  6. 마음에 들 때까지 다시 뽑기를 누르고, 완성되면 MIDI·이미지·링크로 저장해 공유합니다.

이럴 때 유용해요

  • 흥얼거리다 잊어버리곤 하는 멜로디를 악보와 코드로 남겨 두고 싶을 때
  • 작곡을 처음 시작해 코드 진행부터 어떻게 잡아야 할지 막막할 때
  • 가사 한 줄이 떠오르지 않아 초안이라도 붙잡고 고치고 싶을 때
  • 버스킹·동아리 공연에 쓸 자작곡 스케치를 빠르게 여러 개 뽑아 비교할 때
  • 기념일 축하 영상이나 브이로그에 넣을 짧은 배경 멜로디가 필요할 때

허밍이 음표로 바뀌는 원리

마이크에서 들어온 소리를 짧은 구간으로 자른 뒤 각 구간의 파형이 자기 자신과 가장 잘 겹치는 지연 시간을 찾습니다. 그 지연 시간의 역수가 기본 주파수, 즉 음높이입니다. 구한 음높이를 반음 단위 번호로 바꾸고, 비슷한 높이가 이어지는 구간을 하나의 음표로 묶고, 너무 짧은 조각과 소리가 작은 구간은 버립니다. 남은 음표의 간격에서 빠르기를 추정해 8분음표 격자에 맞춰 정리하면 악보가 됩니다. 이어서 음표가 머문 시간을 12개 음이름에 나눠 담아 장조·단조 열두 조성의 전형적인 분포와 비교해 가장 비슷한 조성을 고르고, 마디마다 화음 구성음이 얼마나 오래 울렸는지 따져 코드를 배정합니다.

자주 묻는 질문

인터넷 연결이나 로그인 없이도 곡이 만들어지나요?

네. 코드 진행, 멜로디, 가사, 악보 그리기, 소리 재생까지 모두 브라우저 안에서 계산됩니다. 외부 인공지능 서버로 보내는 데이터가 없고 회원가입도 필요 없습니다. 허밍 녹음도 마찬가지로 마이크 신호를 브라우저 안에서만 분석하며 어디에도 업로드하지 않습니다.

허밍을 넣으면 정말 악보와 코드가 나오나요?

마이크로 부른 소리의 파형에서 자기상관 방식으로 기본 주파수를 추적해 음높이를 구하고, 이어지는 프레임을 하나의 음표로 묶은 뒤 박자 격자에 맞춰 정리합니다. 그 결과로 조성을 추정하고 마디마다 가장 잘 맞는 화음을 골라 코드 진행을 붙입니다. 조용한 곳에서 '루' 또는 '나'로 또렷하게 부르면 정확도가 올라갑니다. 휘파람이나 피아노 단음 연주도 인식됩니다.

만들어진 곡을 다른 프로그램에서 편집할 수 있나요?

결과 화면의 MIDI 파일 저장을 누르면 멜로디·코드·베이스가 각각 들어간 표준 MIDI 파일이 내려받아집니다. 로직, 큐베이스, 스튜디오원, 뮤즈스코어 등 미디를 읽는 프로그램에서 열어 악기를 바꾸거나 이어서 편곡할 수 있습니다. 악보와 코드는 텍스트로도 복사됩니다.

만든 멜로디와 가사를 자유롭게 써도 되나요?

이 도구는 기존 곡을 가져오지 않고 화성학 규칙과 문장 조각을 조합해 결과를 만듭니다. 개인 창작이나 습작에 자유롭게 활용하세요. 다만 알고리즘이 만든 초안이므로 상업적으로 발표할 때는 기존 곡과 비슷한 부분이 없는지 직접 확인하고 다듬어 쓰시길 권합니다.

같은 설정이면 항상 같은 곡이 나오나요?

네. 무드·조성·빠르기·시드가 같으면 언제 어디서 열어도 똑같은 곡이 재현됩니다. 다시 뽑기를 누르면 시드만 하나 올라가 새로운 곡이 되고, 결과 링크에는 시드까지 담기므로 친구가 링크를 열면 같은 곡을 듣게 됩니다. 허밍으로 만든 곡은 추출한 멜로디까지 링크에 담깁니다.

소리가 나지 않아요.

브라우저는 사용자가 화면을 한 번 누른 뒤에야 소리를 낼 수 있습니다. 재생 버튼을 직접 눌러 주세요. 그래도 조용하다면 기기 음량과 무음 스위치를 확인하고, 다른 탭에서 재생 중인 소리를 멈춘 뒤 다시 시도해 보세요.

이 도구가 만든 멜로디·코드·가사는 재미와 습작을 위한 초안입니다. 화성학 규칙과 문장 조각을 조합한 결과이므로 전문 작곡·편곡 교육이나 저작권 검토를 대신하지 않습니다. 마이크 입력은 브라우저 안에서만 분석되며 서버로 전송·저장되지 않습니다. 실명·전화번호 등 민감한 정보는 입력하지 마세요.
