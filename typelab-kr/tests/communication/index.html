대화 스타일 테스트 소개

대화 스타일 테스트는 '하고 싶은 말을 어떻게 전하는가(직진/신중)'와 '대화에서 무엇을 중시하는가(마음/내용)'라는 두 축으로 나의 소통 방식을 알아보는 오락용 테스트입니다. 친구와의 수다, 회의, 단체방 대화 속 나를 떠올리며 10가지 질문에 답해 보세요.

결과에서는 4가지 대화 유형별 특징과 함께, 다른 유형과 대화할 때 오해를 줄이는 팁을 알려 드립니다. 대화 방식에 정답은 없습니다. 서로의 스타일을 아는 것만으로도 많은 갈등이 줄어드니, 자주 대화하는 사람과 함께 해 보세요.

이렇게 진행됩니다

  1. '테스트 시작하기'를 누르고 대화 상황 질문 10개에 답합니다.
  2. 잘 보이고 싶은 모습 말고, 실제 대화에서의 나를 기준으로 고르세요.
  3. 결과 페이지에서 내 대화 유형과 소통 팁을 확인합니다.
  4. 가족·친구·동료와 결과를 비교하면 서로를 이해하는 데 도움이 됩니다.
