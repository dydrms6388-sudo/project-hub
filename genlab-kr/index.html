GenLab은 이런 곳입니다

새 계정을 만들 때, 게임 캐릭터 이름을 지을 때, 디자인 시안에 채울 한글 문장이 필요할 때 — 우리는 하루에도 몇 번씩 "○○ 생성기"를 검색합니다. GenLab은 그렇게 자주 쓰는 생성기들을 광고로 뒤덮인 페이지를 헤매지 않고 바로 쓸 수 있도록 만든 도구 모음입니다.

모든 도구는 순수 자바스크립트로 방문자의 기기에서만 동작합니다. 비밀번호처럼 민감한 결과도 서버로 전송되거나 저장되지 않으며, 보안이 중요한 도구는 브라우저의 암호학적 난수 생성기(crypto.getRandomValues)를 사용합니다.

닉네임·이름·가게 이름·해시태그 사전은 전부 직접 작성한 자체 데이터입니다. 비속어와 실존 인물·브랜드 이름은 제외했으며, 재미있는 조합이 계속 나오도록 꾸준히 다듬고 있습니다.

사용법

  1. 위 카드에서 필요한 생성기를 선택합니다.
  2. 옵션(길이, 스타일, 개수 등)을 고르고 생성 버튼을 누릅니다.
  3. 마음에 드는 결과 옆의 복사 버튼을 누르면 클립보드에 저장됩니다.

자주 묻는 질문

생성 결과가 서버에 저장되나요?

아니요. 모든 생성기는 방문자의 브라우저 안에서만 동작하는 순수 자바스크립트이며, 입력값과 결과는 어떤 서버로도 전송되지 않습니다.

생성 결과를 상업적으로 써도 되나요?

네. 생성된 비밀번호·닉네임·이름·문구는 자유롭게 사용할 수 있습니다. 다만 상호·상표로 쓸 때는 동일 상호·상표가 이미 등록되어 있는지 별도로 확인하세요.

같은 결과를 다시 만들 수 있나요?

대부분의 생성기는 시드(seed) 입력을 지원합니다. 같은 시드와 같은 옵션이면 언제나 같은 결과가 나옵니다. 비밀번호·UUID처럼 보안이 중요한 도구는 예측을 막기 위해 항상 암호학적 난수만 사용합니다.
