난수 생성기 소개

추첨, 순번 정하기, 설문 표본 추출처럼 "공정한 무작위"가 필요한 순간에 쓰는 도구입니다. 기본값은 브라우저의 암호학적 난수 생성기이며, 여기에 한 가지를 더 신경 썼습니다. 흔한 구현인 난수 % 범위 방식은 범위가 2의 거듭제곱이 아닐 때 앞쪽 숫자가 미세하게 더 자주 나오는 모듈로 편향이 생깁니다. 이 도구는 편향 구간에 걸린 난수를 버리고 다시 뽑는 기각 샘플링을 사용해 모든 숫자가 정확히 같은 확률로 나오도록 했습니다.

중복 없이 뽑을 때는 부분 Fisher–Yates 셔플을 사용합니다. "이미 뽑은 숫자면 다시 뽑기"를 반복하는 방식은 범위가 좁고 개수가 많을 때 매우 느려지지만, 셔플 방식은 개수에 비례하는 시간에 끝나고 편향도 없습니다.

시드를 입력하면 mulberry32 결정론적 난수로 바뀝니다. 추첨 과정을 나중에 검증받아야 할 때 유용합니다. 시드와 옵션을 공개해 두면 누구나 같은 결과를 재현해 볼 수 있으니, 조작이 없었음을 보여주는 근거가 됩니다.

사용법

  1. 최소값·최대값으로 범위를 정합니다(음수도 가능).
  2. 뽑을 개수를 입력하고, 같은 숫자가 나오면 안 되는 경우 "중복 없이 뽑기"를 켭니다.
  3. 추첨 결과를 공개·검증해야 한다면 시드를 정해 함께 공지하세요.

자주 묻는 질문

정말 공정한가요?

암호학적 난수 + 기각 샘플링으로 모듈로 편향을 제거했고, 중복 없는 추출은 Fisher–Yates 셔플을 씁니다. 수학적으로 모든 숫자가 동일한 확률입니다.

추첨 결과를 나중에 증명할 수 있나요?

시드를 미리 공개하고 뽑으면 됩니다. 같은 시드·범위·개수·옵션이면 누구나 같은 결과를 재현할 수 있어 사후 검증이 가능합니다.

로또 번호를 뽑아도 되나요?

1~45 범위, 6개, 중복 없이로 설정하면 됩니다. 다만 어떤 난수 도구도 당첨 확률을 높이지 못합니다. 재미로만 사용하세요.
