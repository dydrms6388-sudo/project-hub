닉네임 생성기

직접 만든 한글 사전(형용사 336개 + 명사 386개)에서 스타일에 맞는 조합을 뽑아드립니다. 게임·SNS·커뮤니티 어디든 쓸 수 있는 닉네임을 골라보세요.

    스타일을 고르고 생성 버튼을 누르세요.

    닉네임 생성기 소개

    게임, 커뮤니티, SNS에 가입할 때마다 닉네임 짓기가 제일 오래 걸립니다. 이 닉네임 생성기는 직접 작성한 한글 형용사 336개와 명사 386개를 스타일별로 분류해 두고, 어울리는 조합을 무작위로 뽑아줍니다. 흔한 자동 생성기처럼 어색한 번역투 단어가 아니라, 실제로 쓸 만한 한국어 감성의 조합이 나오도록 사전을 골랐습니다.

    스타일은 네 가지입니다. 귀여운(말랑말랑한 동물·간식 계열), 시크(새벽·필름·모노톤 감성), 게임(전사·랭커 계열), 판타지(정령·별자리 계열). 랜덤 믹스를 고르면 스타일 경계를 넘나드는 의외의 조합이 나옵니다. 사전에는 비속어와 실존 인물·브랜드 이름을 넣지 않았습니다.

    시드(seed)를 입력하면 결정론적 난수(mulberry32)를 사용해 같은 시드 + 같은 옵션에서 항상 같은 결과가 나옵니다. 친구에게 "시드 ○○로 만들어봐"라고 공유하는 식으로 쓸 수 있습니다. 시드를 비우면 암호학적 난수로 매번 새로운 조합을 생성합니다.

    사용법

    1. 스타일과 조합 방식(형용사+명사, 명사+명사 등)을 선택합니다.
    2. 닉네임 글자 수 제한이 있는 서비스라면 글자 수를 지정합니다(공백 제외 기준).
    3. 영문 변환을 켜면 국어의 로마자 표기법 기준 영문 표기를 함께 보여줍니다.
    4. 생성 후 마음에 드는 닉네임을 복사해서 쓰면 됩니다.

    자주 묻는 질문

    생성된 닉네임을 그대로 써도 되나요?

    네, 자유롭게 사용할 수 있습니다. 단어 사전 자체가 일반 명사·형용사 조합이라 저작권 문제가 없습니다. 다만 같은 조합을 다른 사람이 이미 쓰고 있을 수는 있으니 서비스에서 중복 확인은 필요합니다.

    영문 변환은 어떤 규칙인가요?

    국어의 로마자 표기법(문화체육관광부 고시)을 자모 단위로 단순 적용한 근사치입니다. 음운 동화(연음, 자음 동화)까지는 반영하지 않으므로 실제 표준 표기와 다를 수 있습니다.

    같은 결과를 다시 만들 수 있나요?

    시드 칸에 아무 문자열이나 넣으면 됩니다. 같은 시드·스타일·조합 방식·개수라면 언제 다시 와도 같은 목록이 나옵니다.

    이상하거나 불쾌한 조합이 나오면요?

    사전에서 비속어를 제외했지만 무작위 조합 특성상 어색한 결과가 나올 수 있습니다. 재미로 보는 생성 결과이니 마음에 드는 것만 골라 쓰세요.
