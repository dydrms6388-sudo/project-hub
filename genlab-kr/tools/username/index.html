아이디 생성기

이름을 넣으면 로마자 표기 + 숫자 조합으로 아이디 후보 10개를 만들어 드립니다. 가입하려는 사이트의 규칙(글자 수·문자 종류)에 맞는지도 함께 표시합니다.

    이름을 입력하거나 바로 생성을 눌러보세요.

    이 도구는 아이디 "후보"를 만들어 줄 뿐, 실제 사용 가능 여부(중복)는 각 사이트에서 확인해야 합니다.

    아이디 생성기 소개

    회원가입 화면에서 "이미 사용 중인 아이디입니다"를 몇 번씩 만나다 보면 아이디 짓기가 일이 됩니다. 이 아이디 생성기는 한글 이름(또는 좋아하는 단어)을 국어의 로마자 표기법으로 변환한 뒤, 숫자·단어와 여러 방식으로 조합해 아이디 후보 10개를 한 번에 만들어 줍니다.

    사이트마다 아이디 규칙이 다르기 때문에 프리셋을 제공합니다. 가장 흔한 "영문 소문자·숫자 6~12자"를 기본으로, 짧은형·포털형(밑줄 허용)·이메일형(점 허용)을 고를 수 있고, 생성된 각 후보에는 규칙 통과 여부와 글자 수가 표시됩니다. 첫 글자가 숫자인 아이디를 거부하는 사이트가 많아 영문자로 시작하는 후보를 우선 생성합니다.

    사용법

    1. 한글 이름이나 단어를 입력합니다. 비워두면 내장 사전에서 단어를 뽑아 랜덤 아이디를 만듭니다.
    2. 가입할 사이트의 규칙과 가까운 프리셋을 선택합니다.
    3. 생성 버튼을 눌러 후보 10개를 받고, 마음에 드는 것을 복사합니다.

    자주 묻는 질문

    입력한 이름이 어딘가로 전송되나요?

    아니요. 로마자 변환과 조합은 전부 브라우저 안에서 실행되며 네트워크 요청이 없습니다. 다만 아이디는 개인정보가 아니도록 실명 전체보다는 이름·별명 정도만 넣기를 권장합니다.

    로마자 변환이 여권 영문명과 다른데요?

    이 도구는 국어의 로마자 표기법을 자모 단위로 적용합니다. 여권 영문명은 관습 표기(Kim, Lee, Park 등)를 쓰는 경우가 많아 다를 수 있습니다. 아이디 용도로는 어느 쪽을 써도 무방합니다.

    생성된 아이디가 실제로 사용 가능한가요?

    중복 여부는 각 서비스의 데이터베이스에만 있으므로 여기서 확인할 수 없습니다. 후보를 두세 개 복사해 두고 가입 화면에서 차례로 시도하는 것을 추천합니다.
