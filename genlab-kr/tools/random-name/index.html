랜덤 이름 생성기

성씨 60개 빈도표 × 시대별 음절표로 "진짜 있을 법한" 한국 이름을 만듭니다. 소설·시나리오 속 인물, 서비스 테스트용 더미 데이터에 쓰세요.

    옵션을 고르고 생성 버튼을 누르세요.

    무작위 조합 결과이며 특정 실존 인물과 무관합니다. 동명이인이 나올 수 있습니다.

    랜덤 이름 생성기 소개

    소설이나 시나리오의 등장인물, 서비스 화면에 넣을 더미 데이터, 보드게임 캐릭터 — 그럴듯한 한국 이름이 여러 개 필요한 순간은 생각보다 많습니다. 이 랜덤 이름 생성기는 두 가지 자체 데이터를 조합합니다. 하나는 통계청 인구주택총조사의 성씨 분포를 참고해 만든 성씨 60개 빈도표(김·이·박이 실제 비율대로 자주 나옵니다), 다른 하나는 연대별로 흔했던 이름 음절을 정리한 시대별 음절표입니다.

    시대 옵션은 "그 연대에 태어난 사람 이름 느낌"을 냅니다. 70년대생을 고르면 ○철·○숙 같은 조합이, 00년대생을 고르면 서연·도윤 같은 조합이 자주 나옵니다. 음절표는 특정 인물 목록이 아니라 흔히 쓰이는 음절의 조합이므로, 생성된 이름이 실존 인물과 같아도 우연의 일치입니다.

    시드를 입력하면 같은 옵션에서 항상 같은 목록이 나오므로, 팀원과 같은 더미 데이터를 공유하거나 문서에 재현 가능한 예시를 넣을 때 편리합니다.

    사용법

    1. 성별과 시대 느낌을 선택합니다.
    2. 필요한 개수를 정하고 생성 버튼을 누릅니다.
    3. "외자 이름 섞기"를 켜면 약 5~6개 중 1개꼴로 외자 이름(김준, 이솔 등)이 섞입니다.
    4. 로마자 표기를 켜면 명단·자막용 영문 표기를 함께 보여줍니다.

    자주 묻는 질문

    실존 인물 이름이 나올 수도 있나요?

    흔한 성씨와 흔한 음절의 조합이므로 동명이인은 얼마든지 나올 수 있습니다. 이 도구는 특정 인물 데이터를 전혀 쓰지 않으며, 일치는 순전히 우연입니다. 실존 인물을 지칭하는 용도로 사용하지 마세요.

    성씨는 어떤 기준으로 나오나요?

    통계청 인구주택총조사에 나타난 성씨 분포를 참고해 만든 근사 빈도표(60개 성씨)를 가중치로 사용합니다. 실제 인구 비율처럼 김·이·박·최·정 순으로 자주 등장합니다.

    시대별 느낌은 얼마나 정확한가요?

    연대별로 흔했던 음절을 정리한 "느낌" 수준의 데이터입니다. 공식 통계의 인기 이름 순위표를 그대로 옮긴 것이 아니므로, 창작·더미 데이터 용도에 맞는 참고용으로 봐주세요.

    아기 이름 짓기에 써도 되나요?

    아이디어를 얻는 용도로는 좋습니다. 다만 무작위 조합이므로 한자 의미·발음·항렬 같은 요소는 전혀 고려되지 않습니다. 실제 작명에는 참고용으로만 쓰세요.
