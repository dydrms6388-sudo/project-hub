해시태그 생성기

키워드 하나만 넣으면 관련 카테고리를 찾아 해시태그를 뽑아 드립니다. 태그는 카테고리별로 직접 정리한 600개 사전에서 나옵니다.

키워드를 입력하거나 카테고리를 선택하세요.

해시태그는 노출을 보장하지 않습니다. 게시물과 관계없는 인기 태그를 대량으로 붙이면 오히려 도달이 줄 수 있으니, 내용과 맞는 태그만 골라 쓰세요.

해시태그 생성기 소개

게시물을 올릴 때마다 태그를 처음부터 다시 떠올리는 건 소모적입니다. 이 도구는 카페·디저트, 맛집·음식, 여행, 운동·헬스, 패션, 뷰티, 일상·감성, 반려동물, 공부·자기계발, 육아 10개 카테고리에 각 60개씩 총 600개의 해시태그를 직접 정리해 두고, 입력한 키워드와 가장 가까운 카테고리를 찾아 태그를 조합합니다.

키워드 매칭은 카테고리별 동의어 사전으로 이뤄집니다. "라떼"를 넣으면 카페 카테고리가, "필라테스"를 넣으면 운동 카테고리가 잡힙니다. 매칭된 카테고리가 둘 이상이면 가장 관련 높은 카테고리 태그를 60% 정도, 나머지를 30% 정도 섞어 자연스러운 조합을 만듭니다. 뽑힌 태그는 눌러서 끄고 켤 수 있어 필요 없는 것만 빼고 복사할 수 있습니다.

한 가지는 분명히 해두는 편이 좋습니다. 해시태그는 노출을 보장하지 않습니다. 게시물 내용과 무관한 인기 태그를 대량으로 붙이는 방식은 플랫폼이 스팸으로 판단할 수 있어 오히려 손해입니다. 내용과 맞는 태그를 10~20개 정도 고르는 편이 안전합니다.

사용법

  1. 키워드를 입력합니다. 여러 개는 쉼표로 구분하세요(예: 카페, 디저트).
  2. 원하는 카테고리를 직접 눌러 추가할 수도 있습니다.
  3. 태그 개수를 정하고 뽑기 버튼을 누릅니다.
  4. 필요 없는 태그를 눌러 끈 다음 "전체 복사"로 붙여 넣습니다.

자주 묻는 질문

해시태그를 몇 개 쓰는 게 좋나요?

플랫폼별 상한은 다르지만(인스타그램은 게시물당 30개), 상한을 채우는 것이 유리하다는 근거는 없습니다. 내용과 실제로 맞는 태그 10~20개를 고르는 쪽이 일반적으로 권장됩니다.

태그 데이터는 어디서 가져온 건가요?

카테고리별로 직접 작성한 자체 사전입니다. 특정 브랜드나 실존 상호를 지칭하는 태그는 넣지 않았습니다.

같은 태그 조합을 다시 얻고 싶어요.

시드를 입력하면 같은 키워드·카테고리·개수 조건에서 항상 같은 태그 목록이 나옵니다. 시리즈 게시물의 태그를 통일할 때 쓸 수 있습니다.
