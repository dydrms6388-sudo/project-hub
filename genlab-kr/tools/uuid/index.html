UUID 생성기

암호학적 난수로 만드는 표준 UUID. 완전 무작위 v4와 생성 시각 순으로 정렬되는 v7을 지원합니다.

    생성 버튼을 누르세요.

    UUID 생성기 소개

    UUID(Universally Unique Identifier)는 중앙 서버의 도움 없이도 전 세계에서 겹치지 않는 식별자를 만들기 위한 128비트 값입니다. 이 도구는 브라우저의 암호학적 난수 생성기(crypto.getRandomValues)로 UUID를 만들며, 만들어진 값은 어디에도 전송되지 않습니다.

    v4는 122비트가 완전 무작위입니다. 값만 봐서는 언제 만들어졌는지 알 수 없고, 정렬해도 아무 의미가 없습니다. v7은 상위 48비트에 Unix 시각(밀리초)을 넣고 나머지를 무작위로 채웁니다. 그래서 문자열을 그대로 정렬하면 생성 시각 순서가 되며, 데이터베이스 인덱스에서 v4보다 삽입 성능이 유리합니다. 반대로 값에 생성 시각이 노출되므로 시각을 감춰야 하는 곳에는 v4를 쓰세요.

    사용법

    1. 버전(v4/v7)을 선택합니다. 데이터베이스 기본키라면 v7, 공개되는 토큰이라면 v4가 무난합니다.
    2. 필요한 개수를 입력합니다(최대 500개). 화면에는 200개까지 보여주고, 전체는 "전체 복사"로 받을 수 있습니다.
    3. 대문자·하이픈 제거·따옴표 감싸기 옵션으로 코드에 바로 붙일 형태를 만듭니다.

    자주 묻는 질문

    UUID가 중복될 확률이 있나요?

    v4는 122비트 무작위라서 초당 10억 개를 100년간 만들어도 중복 확률이 무시할 수준입니다. 다만 난수 품질이 나쁘면 이야기가 달라지므로, 이 도구는 예측 불가능한 암호학적 난수만 사용합니다.

    UUID를 비밀 토큰으로 써도 되나요?

    v4는 무작위성이 충분해 추측이 어렵지만, UUID는 본래 "고유함"이 목적이며 "비밀"이 목적이 아닙니다. 로그·URL에 남기 쉬우므로 인증 토큰에는 별도의 비밀값을 쓰는 편이 안전합니다. v7은 시각이 드러나므로 특히 부적합합니다.

    v7은 정확히 어떤 순서로 정렬되나요?

    상위 48비트가 Unix 밀리초 타임스탬프라서, 문자열을 사전순으로 정렬하면 생성 시각 오름차순이 됩니다. 같은 밀리초에 만든 값들 사이의 순서는 무작위입니다.
