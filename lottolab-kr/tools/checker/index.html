로또 당첨 확인

내 번호 6개를 고르고 회차를 선택하면 등수를 즉시 판정합니다.

선택 0 / 6

당첨 확인 도구 소개

로또 당첨 확인 도구는 내가 산 번호 6개를 입력하면 선택한 회차의 당첨번호와 비교해 몇 개가 일치하는지 세고, 로또 6/45 공식 등수 기준(1등~5등)에 따라 결과를 알려줍니다. 번호판에서 번호를 누르기만 하면 되고, QR이나 사진 업로드 없이 브라우저 안에서 즉시 판정됩니다.

등수 기준은 다음과 같습니다: 본번호 6개 일치 = 1등, 5개 일치 + 보너스 번호 일치 = 2등, 5개 일치 = 3등, 4개 일치 = 4등, 3개 일치 = 5등(고정 5,000원). 2개 이하 일치는 낙첨입니다. 보너스 번호는 오직 2등 판정에만 쓰인다는 점을 기억하세요.

마지막으로 입력한 번호는 다음 방문 때 다시 입력하지 않도록 이 브라우저에만(localStorage) 저장됩니다. 서버 전송은 없습니다.

사용법

  1. 번호판에서 내 번호 6개를 선택합니다.
  2. 확인할 회차를 선택합니다(기본값은 최신 회차).
  3. 당첨 확인을 누르면 일치 개수와 등수가 표시됩니다.
  4. 당첨금 실수령액이 궁금하면 로또 세금 가이드를 참고하세요.

자주 묻는 질문

보너스 번호는 언제 쓰이나요?

보너스 번호는 본번호 5개를 맞힌 경우에만 의미가 있습니다. 5개 일치 + 보너스 일치면 2등, 보너스가 틀리면 3등입니다. 6개 전부 일치(1등) 판정에는 보너스가 쓰이지 않습니다.

입력한 번호가 서버에 저장되나요?

아니요. 판정은 전부 브라우저에서 실행됩니다. 편의를 위해 마지막 번호를 이 기기의 localStorage에만 저장하며, 초기화 버튼으로 지울 수 있습니다.

지난 회차 번호도 확인할 수 있나요?

네. 회차 선택 목록에서 수집된 모든 회차를 고를 수 있습니다. 참고로 당첨금 지급 기한은 지급 개시일로부터 1년이므로, 오래된 복권은 기한을 꼭 확인하세요.
