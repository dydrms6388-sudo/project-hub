개인정보처리방침

writelab은 이용자가 입력한 글과 개인정보를 서버로 수집하지 않습니다.

1. 수집하지 않는 정보

writelab의 모든 도구는 브라우저에서 실행되는 정적 페이지입니다. 이용자가 입력한 자기소개서·글·키워드·날짜 등은 서버로 전송되지 않으며, 운영자는 그 내용을 확인할 수 없습니다. 회원가입 절차가 없으므로 이름·전화번호·주민등록번호·이메일 등 개인 식별 정보를 요구하거나 저장하지 않습니다.

2. 브라우저 저장(localStorage)

일부 도구에는 작성 중인 내용을 잃지 않도록 "이 브라우저에 임시 저장" 옵션이 있습니다. 이 옵션을 켠 경우에만 입력 내용이 이용자가 사용하는 기기의 localStorage에 저장됩니다. 저장된 값은 해당 브라우저 안에만 존재하고 외부로 전송되지 않으며, 옵션을 끄거나 브라우저의 사이트 데이터를 삭제하면 함께 삭제됩니다.

3. 외부 전송·외부 API

이 사이트의 도구는 맞춤법 검사, 번역, 인공지능 처리 등 어떤 외부 API도 호출하지 않습니다. 모든 계산과 판정은 페이지에 포함된 자바스크립트와 정적 데이터 파일만으로 수행됩니다.

4. 쿠키

운영자가 직접 설정하는 쿠키는 없습니다. 향후 접속 통계나 광고가 도입되어 제3자 쿠키가 사용될 경우, 이 방침을 먼저 갱신해 고지합니다.

5. 이용자 권리

브라우저에 저장된 값은 이용자가 언제든 직접 삭제할 수 있습니다. 각 도구의 "지우기" 버튼, 임시 저장 옵션 해제, 브라우저 설정의 사이트 데이터 삭제 중 어떤 방법을 써도 즉시 삭제됩니다.

6. 방침 변경

이 방침이 변경되면 이 페이지의 내용을 갱신합니다. 최종 갱신일: 2026년 8월.
