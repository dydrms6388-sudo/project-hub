# 콘텐츠 초안 (Phase 2 — 매일 1개)

`drafts/YYYY-MM-DD.md` = 그날 자동 생성된 **초안 1개**. 게시된 글이 아니다.

## 흐름

```
GitHub Actions (매일 06:10 KST)
  → npm run daily-post            # salon/scripts/daily-post.mjs
  → content/drafts/YYYY-MM-DD.md  # master 에 커밋 ([skip ci])
  → 사장님이 읽고 고쳐서 직접 게시
```

자동 게시는 없다. 블로그·스레드에 올리는 건 사람이 한다.

## 초안 1개에 들어있는 것

| 섹션 | 쓰는 곳 |
| --- | --- |
| `## 제목` | 블로그 제목 (후킹 형식 5종 중 그날 것) |
| `## 블로그 본문` | 네이버 블로그 등 800~1200자 |
| `## 스레드 캡션` | 스레드·인스타 150~300자 |
| `## 사장님 확인` | 게시 전에 사실 확인할 3가지 |
| `## 해시태그` | 로컬 5 + 시술 5 + 일반 5 = 15개 (스크립트가 직접 조합) |

front matter 의 `topic` 키로 최근 2주 주제를 피해 돌아간다 (주제 풀 30개 = 한 달 순환).

## 규칙 (스크립트가 강제한다)

- **고객 데이터·사진을 쓰지 않는다.** 스크립트는 Supabase 에 접근하지 않고 주제 기반
  일반 콘텐츠만 쓴다 → `consent_photo` 동의 문제가 생길 여지가 없다.
- 생성물은 `lib/content.ts` 의 `validateDraft()` 를 통과해야 파일로 남는다. 섹션 누락,
  분량 미달, 의학적 치료 주장, 효과 보장, 외모 비하, 전화번호·주민번호, 플레이스홀더
  잔재가 하나라도 걸리면 1회 재작성시키고, 그래도 걸리면 **아무것도 쓰지 않고 실패**한다.
- 가격은 금액 대신 구성 기준만 설명한다.

## 수동 실행

```bash
cd salon
ANTHROPIC_API_KEY=... npm run daily-post              # 오늘 자 (이미 있으면 스킵)
SALON_POST_DATE=2026-10-25 npm run daily-post -- --force
```

리포 Actions 탭 → "정화 머리방 콘텐츠 초안 (매일 1개)" → Run workflow 로도 날짜·강제
재생성을 지정할 수 있다.

## 끄는 방법

워크플로를 disable 하거나 리포 시크릿 `ANTHROPIC_API_KEY` 를 지운다. 키가 없으면
스크립트는 경고만 남기고 성공 종료하며 커밋도 하지 않는다. (하루 1회 유료 API 호출)
