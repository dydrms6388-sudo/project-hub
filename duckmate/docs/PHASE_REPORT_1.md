## 4. 다음 Phase 선행조건

### Phase 2(게임/리텐션) 진입 전 반드시 — 순서대로

1. **소유자 제공**: Vercel 계정 · Supabase 프로젝트(서울 리전). 이 둘만 있으면 배포는 문서 절차대로 진행된다.
2. **본인인증 결정 (블로킹)**: 프로덕션에서 stub 이 차단되므로(G2-01), PortOne 실연동 없이는 아무도 Lv1/Lv2 가 될 수 없다 = 매칭·채팅 불가. 둘 중 하나를 골라야 한다.
   - (a) 포트원 계약 후 `PortOneVerifier` 구현 → 정상 오픈
   - (b) 친구 모드만 여는 축소 오픈 → 데이팅·채팅 비활성 (추가 작업 필요)
3. **E2E 실제 실행**: 로컬 Supabase + 시드 + `IDENTITY_VERIFIER=stub` + Auth 이메일 확인 OFF (`docs/agents/28_e2e.md` 사전조건 5항).
4. **실제 회원가입/매칭/채팅 1회 성공 기록** → `DEPLOY_LOG.md` §6 체크리스트.
