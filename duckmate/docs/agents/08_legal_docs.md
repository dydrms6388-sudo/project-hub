## 다음 에이전트에게 넘기는 결정사항

1. **파일 위치·형식 확정**: 법적 문서 6종은 `apps/web/content/legal/{terms,privacy,location,youth,community,refund}.md`. 각 파일은 YAML frontmatter(`title`, `slug`, `version: 0.1.0`, `effectiveDate: "{{EFFECTIVE_DATE}}"`, `draft: true`)를 가지며, **`draft: true`인 동안 렌더링 시 "법률 검토 전 초안" 배너를 노출해야 한다** (E4·E5 공통).
2. **플레이스홀더 치환 규약**: 변수는 전부 `{{VAR}}` 형태. 사용된 변수 전체 목록 = `{{COMPANY_NAME}}`, `{{SERVICE_NAME}}`, `{{CEO_NAME}}`, `{{BIZ_REG_NO}}`, `{{MAIL_ORDER_NO}}`, `{{ADDRESS}}`, `{{PRIVACY_OFFICER}}`, `{{YOUTH_OFFICER}}`, `{{CONTACT_EMAIL}}`, `{{EFFECTIVE_DATE}}`, `{{SUPABASE_REGION_COUNTRY}}`(privacy 전용 — 국외이전 국가, Supabase 프로덕션 리전 확정 후 기입). 치환 값의 단일 소스는 `apps/company/config/company.ts`(스펙 §7)이며, **web도 동일 값을 참조**해야 한다(값 중복 정의 금지). 미입력 변수는 `[TODO_사업자정보]`로 렌더 + 빌드 경고(스펙 §0-4, 차단은 안 함).
3. **문서 간 참조 구조 확정**: community(가이드라인)와 refund(환불정책)는 이용약관 제12·13·15조가 명시적으로 "약관의 일부"로 편입한다. 문서를 수정할 때 terms의 해당 조 번호와 함께 움직여야 한다(E4는 문서 간 상호 링크를 걸 것).
4. **약관 내 수치는 원본 정책 문서에 종속**: 마스킹 해제(72h+양측 Lv2), 스냅샷 범위(72h/200개), 보존 기간(evidence 종결+1년, 감사로그 3년, 접속로그 3개월, CI·번호 해시 영구), 제재 5등급, SLA(24h/P0 1h), 이의제기(30일/1회/7일), 환불 계산식(일할 30일 기준, 슈퍼라이크 단가 ₩980)은 05·04 문서의 확정값을 그대로 옮긴 것이다. **D4·D5·D6 구현이 이 수치와 달라지면 약관 위반이 되므로, 수치 변경 시 반드시 이 6종 문서를 함께 개정**해야 한다.
5. **location.md는 조건부 문서**: 현재 초안은 "행정구역 region_code만 수집·실시간 위치 미수집"을 전제로 작성했다. B1의 위치기반서비스사업 신고 필요 여부 판정 결과에 따라 (a) 신고 대상 아님 → 현재 형태(고지 성격) 유지 가능, (b) 신고 대상 → 위치정보법 표준 약관 체계(사업 신고번호 기재 등)로 개정 필요. **실시간 위치 기능을 도입하는 순간 사업 신고+약관 전면 개정+별도 동의가 선행 조건**임을 문서 제8조에 박아두었다.
6. **버전 관리 규약**: 문서 개정 시 frontmatter `version`을 semver로 올리고, 회원에게 불리한 변경은 30일 전(그 외 7일 전) 공지 조항(terms 제3조, privacy 제12조)을 지켜야 한다. D1/D8은 회원별 "동의한 약관 버전" 기록을 고려할 것(가입 시 version 스탬프 — 스키마에 없으면 `audit_logs`로 대체 가능).
7. **E4 노출 의무 지점**(하단 상세): 가입 화면(약관·개인정보 동의), 설정 → 법적 고지 목록, 구독 결제 화면(환불정책 1탭 접근 — A4 다크패턴 가드 #10), 신고 플로우(커뮤니티 가이드라인 링크), 제재 통보 화면(가이드라인 위반 조항 + 이의제기 안내).

## 2. 각 문서 핵심 조항 요약

### terms.md (이용약관)
- **제5조 만 19세 전용**: 만 나이 기준, 가입 거부 시 입력값 미저장, 사후 확인 시 즉시 정지+파기 — A5 3중 게이트의 약관 근거.
- **제7조 인증 레벨 0~3 표**: A5 §1.2 매트릭스를 약관 언어로 옮김. "매칭·채팅은 양측 Lv2 이상"을 약관 차원에서 확정(미인증 DM 불가의 계약적 근거).
- **제9조 연락처 보호**: 마스킹(72h+양측 Lv2 해제, 이메일·URL·계좌 영구)을 서비스의 정당한 조치로 명문화 — "왜 내 메시지를 가리냐" 민원의 방어 근거.
- **제13조 신고·제재**: 24h SLA(P0 1h), 신고 시 72h/200개 스냅샷 보존 고지, 제재 5등급, CI·번호 해시 블랙리스트, 이의제기 30일/1회/7일, **제재 중에도 미사용 유료분 환불**(몰수 금지 — A4 §5.1).
- **제14~15조 유료서비스**: 자동갱신 고지·3일 전 통지·2뎁스 해지(다크패턴 가드의 약관 반영), 환불은 refund.md로 위임.
- **제17조 게시물**: UGC 라이선스는 "서비스 제공 목적 범위 내"로 한정 + 검색엔진 비노출(noindex) 약속 + 외부 마케팅 무단 사용 금지.
- **제19조 면책**: 회원 간 분쟁 면책하되 "고의·중과실 및 강행법규상 책임은 배제하지 않음" 단서로 무효 리스크 완화.

### privacy.md (개인정보처리방침)
- **제1조 수집 항목표**: 필수/선택 구분. 사진은 **선택**(M6 — 스킵해도 매칭·채팅 가능). 주민번호·민감정보 미수집, CI·전화번호는 해시만, 실시간 위치 미수집 명시.
- **제3조 보유 기간표**: A5 §4.3을 그대로 법문화 — **"대화는 신고가 접수된 경우에만 별도 보존"** 명문화(A1/PRD가 요구한 마케팅 자산 문구), evidence 분쟁 종결+1년, 감사로그 3년, 접속로그 3개월, 영구정지 해시 영구, 탈퇴 시 본인 발신분 지체 없이 파기 + 상대 화면 사본은 상대 탈퇴 시까지. 전자상거래법 법정 보존(5년/3년/6개월) 병기.
- **제5조 제3자 제공 없음**: 수사기관 예외는 A5 §4.4 절차(적법 절차 확인, 기록, 사후 통지)로 한정.
- **제6조 처리위탁**: Supabase / Vercel / 포트원(+본인확인기관) / 토스페이먼츠 4개사 표.
- **제7조 국외이전**: Supabase·Vercel 국외 처리 고지(개인정보보호법 §28-8 필수 기재사항 형식). 리전 국가는 `{{SUPABASE_REGION_COUNTRY}}`로 보류.
- **제8조 정보주체 권리**: 데이터 다운로드·탈퇴 셀프서비스(F-PRF-03), 소송 목적 본인 대화 사본 제공(상대 마스킹).
- **제10조 개인정보 보호책임자**: `{{PRIVACY_OFFICER}}`, 수사기관 창구 단일화.

### location.md (위치정보 이용약관)
- **제2조**: 수집 = 이용자가 직접 선택한 행정구역 단위 region_code 1건뿐. GPS·이력·단말 위치 권한 **미수집/미요청** 명시. IP는 보안 로그로만.
- **제4조**: 타 회원에게 행정구역 명칭만 노출, 거리 계산·실시간 위치 기능 부존재("위치 실시간 노출 안 함" 스펙 §1 반영).
- **제8조**: 실시간 위치 기능 도입 시 사업 신고+전면 개정+별도 동의 선행 — B1 판정과 연결되는 안전핀.

### youth.md (청소년보호정책)
- **제2조 3중 차단**: A5 §1.3(가입 게이트/본인인증 게이트/런타임 게이트)을 정책 언어로.
- **제3조**: `SAFETY_MINOR` 신고 = P0, 1시간 내 임시 잠금, 확인 시 영구정지+파기, 미성년자 접촉 시도 성인은 영구정지+수사기관 통보.
- **제5조**: 청소년보호책임자 `{{YOUTH_OFFICER}}` (정보통신망법 §42-3 대응).

### community.md (커뮤니티 가이드라인)
- **제2조**: 금지행위를 A5 §2 신고 사유 택소노미 **18개 코드와 1:1 대응**하는 표로 작성(코드 병기 — E3 신고 UI의 2단 선택과 문구 동기화 가능). `CONTENT_SELF_HARM`은 제재가 아닌 보호 절차(109 안내)로 분기함을 명시.
- **제3조**: 24h/P0 1h SLA, 스냅샷 보존 고지, 신고자 익명, 자동 숨김+원클릭 차단, 무고 신고 남용 제한(30일 내 기각 5건 → 30일 제한).
- **제4조**: 제재 5등급 표 + 즉시 영구정지 사유 + 누진 규칙 + 자동 임시조치는 최대 2등급·24h 내 사람 확정 + 이의제기 4-eyes.
- **제5조**: 안전 만남 수칙(공공장소, 스캠 신호, 연락처 72h 정책의 이용자 안내).

### refund.md (환불정책)
- **제2조**: 7일 청약철회 + "즉시 이용 개시를 이유로 전면 배제하지 않고 사용분 공제 환불"(A4 §5.1 자발 정책).
- **제3조**: 구독 환불 계산식·예시를 A4 §5.2 **그대로**(d=올림 최소 1일, 월 30일 고정, 슈퍼라이크 단가 ₩980, 예시 6,290원). 비소모 혜택 이중 공제 금지.
- **제4조**: 소모성 계산식(팩 `4,900×미사용/5`, 부스트 사용 후 0) + 차감 순서가 구매분 보존(유저 유리) 설계임을 고지.
- **제5조**: 해지=기간 말 갱신 중단(2뎁스), past_due 3일 유예.
- **제6조**: 회사 귀책 전액 환불(+표시·광고 상이 시 안 날부터 30일 철회 — 전상법 §17③).
- **제7조**: **영구정지 회원도 미사용분 환불**(몰수 금지).
- **제8조**: 앱 내 신청 폼, 영업일 3일 SLA, 지연배상(전상법 §18), 과도한 서류 요구 금지.
- **제9조**: IAP는 마켓 정책 위임 + 환불 확인 시 혜택 회수(A4 §6.2).

| 11 | community 제3조 5항 | 신고 남용자 신고 기능 30일 제한이 이용자 권리(신고권) 제한으로서 과도하지 않은지 |
| 12 | 전 문서 | `{{EFFECTIVE_DATE}}` 확정 및 최초 시행 공고 절차(사전 공지 기간) 설계 |

## 4. E4(설정 화면)·E5(회사 사이트) 렌더링 지침

### 공통 (packages 레벨)
- 6개 `.md` 파일을 단일 소스로 사용한다. **web과 company가 각자 사본을 두지 않는다** — 빌드 시 `apps/web/content/legal/`을 양쪽에서 읽거나 공용 패키지로 승격(구현 재량, 사본 복제만 금지).
- frontmatter 파싱 → `title`/`version`/`effectiveDate` 표시. `draft: true`면 페이지 상단에 "본 문서는 법률 검토 전 초안입니다" 경고 배너(프로덕션 게이트 G-4는 플레이스홀더 허용이므로 배너로 초안임을 정직하게 노출).
- `{{VAR}}` 치환: 빌드 타임에 `apps/company/config/company.ts` 값으로 치환. 값이 비어 있으면 `[TODO_사업자정보]` 텍스트 렌더 + 빌드 경고(차단 금지 — 스펙 §0-4). `{{EFFECTIVE_DATE}}` 미정 시 "시행일: 정식 오픈 시 확정" 렌더.
- 조항 앵커: `제N조` 헤딩에 id를 부여해 `#제13조` 딥링크 가능하게(제재 통보·페이월에서 특정 조항 링크용).
- 법적 페이지는 **공식 콘텐츠이므로 인덱싱 허용**(UGC noindex 대상 아님), sitemap 포함(E6).

### E4 (apps/web 설정 화면)
1. **가입(E1과 협업)**: 약관 동의 체크는 [이용약관] [개인정보 수집·이용] 개별 동의 + (선택) 광고성 정보 수신 동의. 각 항목에서 해당 문서 전문을 바텀시트/새 화면으로 열람 가능. 동의 시점의 문서 `version`을 기록(감사 목적).
2. **설정 → 약관 및 정책** 목록 화면: 6개 문서를 title 순서(이용약관 → 개인정보처리방침 → 위치정보 → 청소년보호 → 커뮤니티 가이드라인 → 환불정책)로 나열, 각각 전문 뷰(마크다운 렌더). 오프라인 캐시 불필요, 웹뷰로 충분.
3. **결제/구독 관리 화면**: 환불정책을 **1탭**으로 열람 가능해야 함(A4 다크패턴 가드 #10). 결제 확인 화면에 "환불정책" 링크 + 자동갱신 고지 문구(terms 제14조와 동일 문구).
4. **신고 플로우(E3과 협업)**: 신고 사유 선택 UI의 카테고리·명칭을 community.md 제2조 표와 동일하게 유지(코드 18종 1:1). "커뮤니티 가이드라인 보기" 링크 포함.
5. **제재 통보 화면**: 위반한 가이드라인 조항(community 제2조 해당 행 앵커) + 제재 등급(제4조) + 이의제기 방법(30일/1회) 링크.
6. **탈퇴 플로우**: privacy 제3조(파기 기준)와 제8조(데이터 다운로드) 요약 고지 + 다운로드 버튼을 탈퇴 확인 전에 노출.

### E5 (apps/company 회사 사이트)
1. **법적 고지 페이지**(Phase 1 필수): 사업자 정보(상호·대표·사업자번호·통신판매업번호·주소·개인정보보호책임자·청소년보호책임자) + 6개 문서 전문 링크. footer 전역에 [이용약관] [개인정보처리방침] [청소년보호정책] 상시 링크(개인정보처리방침은 굵게 — 관행).
2. **안전과 신뢰 페이지**: community.md 제3~5조(24h SLA, 신고 처리, 안전 수칙)와 youth.md 요약을 마케팅 카피로 재가공해 노출하되, 수치(24h/1h/72h)는 문서와 반드시 일치시킬 것(불일치 시 표시광고법 리스크).
3. 정적 SSG이므로 빌드 타임 치환만 사용, 클라이언트 fetch 금지. 문서 페이지는 sitemap 포함.
