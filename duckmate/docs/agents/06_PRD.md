### 1. 그룹 공통 확정 사항 (B/C/D/E 전원)

1. **모드 2원제**: 성별 무관 `friend` 모드 + 인증 회원 전용 `dating` 모드. 온보딩 기본 동선은 "친구 모드로 가볍게 시작 → 만족 신호(첫 대화 10턴 이상 등) 후 데이팅 전환 CTA" (A2). 친구 모드는 2등 시민이 아니다 — 성비 완충재이자 전환 퍼널의 본체다 (A1).
2. **인증 레벨 0~3 게이트**는 A5 §1 표를 그대로 구현한다. 핵심: `likes`는 Lv1부터(일 3회 제한), `matches` 생성·채팅·이미지·결제·데이팅 모드는 양측 Lv≥2, 이벤트 호스팅·인증 뱃지는 Lv3.
3. **만 19세 미만 3중 게이트**: 가입 시 `birth_date` 자기신고 → Lv2에서 PASS 생년월일로 재검증(미달 시 즉시 banned+파기 큐) → 모든 노출·접촉 로직에 `verify_level >= 2` 런타임 조건 (A5 §1.3).
4. **과금 원칙**: "대화 개시 유료화 금지, 노출량·편의만 유료화" (A1). 무료 유저도 매일 추천 5명 + (Phase 2부터) 궁합 카드 1장 + 매칭 + 대화가 반드시 가능하다. 티어·가격·한도는 A4 `TIER_LIMITS` 상수가 단일 진실이며 `packages/db`에서만 정의한다.
5. **다크패턴 금지 10항** (A4 §4)은 C2(디자인 토큰·컴포넌트 제외 목록), D6(서버 검증), E4(UI), G1(E2E "해지 3탭 이내" 케이스)이 공동 집행한다. 카운트다운·재고 카피 컴포넌트는 아예 만들지 않는다.
6. **일일 리셋 = KST 06:00, 푸시 = 일 최대 2건 고정 슬롯제** (슬롯1 08:00 데일리 앵커, 슬롯2 이벤트성 12:00~21:00 최상위 1건, 이월 없음). 죄책감 카피 금지 목록은 A3 §3.2가 고정 제약 (D7, F3).
7. **퍼널 이벤트 이름은 A3 §4.1 스네이크케이스를 그대로 사용** (`app_open`, `daily_card_open`, `match_created`, `first_message_sent`, `paywall_source` 등). 임의 개명 금지. D1은 `analytics_events(id, profile_id, name, props jsonb, created_at)`를 확보한다.
8. **첫 대화 제안 카드는 Phase 1 필수** (게임과 무관한 §1 차별점). 매칭 생성 시 서버가 공통 취미 기반 제안 3개를 `matches.first_suggestion(jsonb)`에 미리 생성 (D3, D4, E3). Phase 2에서 소스에 `battle|quiz` 추가.
9. **콜드스타트 방침**: 론칭 범위 = 서울·수도권 × 취미 카테고리 3~5개(보드게임·공연/콘서트·러닝/클라이밍·카페투어·애니/웹툰). "추천 0명" 빈 화면 절대 금지 — 추천 부족 시 취미친구 후보·프로필 보완 퀘스트(Phase 1)·취향 배틀(Phase 2)로 폴백 (D3, E2). 확장 기준선: 버킷당 활성 300명·성비 6:4 이내(D8 대시보드로 판정).
10. **안전은 마케팅 자산**: 신고 24h SLA(P0는 1h 임시조치)·미인증 DM 불가·"대화는 신고 시에만 스냅샷 보존"을 회사 사이트(C4/E5)·온보딩 첫 화면·스토어 문구에 전면 노출한다 (A1).

## 1. 제품 개요 + 핵심 가치 제안

**덕메이트(DuckMate)** — "같은 걸 좋아하는 사람이랑 만나는 앱." 외모 스와이프가 아니라 **취미·덕질 궁합 → 함께 하는 활동 → 만남** 순서의 데이팅/취미친구 서비스다.
타겟은 20~34세, 뚜렷한 취미·팬덤이 있고 "취미가 안 맞는 사람과는 못 만나겠다"는 사람(페르소나 P1 덕질 몰입형·P2 취미 입문형·P3 오프모임 선호형·P4 온라인 대화 선호형).

핵심 가치 제안 4가지:
1. **첫 화면이 사진이 아니라 덕질 카드** — 취향으로 평가받고 싶은 외모 스와이프 피로층을 받아주는 유일한 앱.
2. **설명 가능한 매칭** — 궁합 % + 이유 3줄(취미 자카드 + 5축 퀴즈 코사인 + 시간대 겹침 + 상호 신호). 경쟁 5개 앱 모두 부재.
3. **대화를 돈으로 잠그지 않음** — 무료도 매일 추천·매칭·대화 보장, 유료는 양과 편의만 확장. 국내 데이팅앱 과금 불신의 역포지셔닝.
4. **신뢰를 하드 게이트로** — 만 19세 미만 완전 차단, 미인증 간 DM 불가, 신고 24h SLA, 대화는 신고 시에만 스냅샷 보존. 매칭 후엔 "같이 할 수 있는 것" 제안 카드가 어색함을 대신 깬다.

| 안전 | 신고 `handled_at − created_at` P95 / P0 임시조치 | ≤ 24h / ≤ 1h |
| 수익 (Phase 3+) | `paywall_source`별 전환율, 티어 분포 | 론칭 후 베이스라인 수립(목표치는 Phase 3에서 확정) |
