# A2 — 페르소나 / JTBD (덕메이트 DuckMate)

> 근거: `ORCHESTRATOR_SPEC.md` §1(서비스 정의·타겟), §5(핵심 루프·게임 요소), §6(유료 구조).
> 타겟: 20~34세, 뚜렷한 취미/팬덤 보유, "취미가 안 맞는 사람이랑은 못 만나겠다"는 사람.
> 전제: 초기에는 성별 무관 **친구 모드**와 인증 회원 전용 **데이팅 모드**를 분리 운영.

## 다음 에이전트에게 넘기는 결정사항

1. **페르소나 4종 확정** — P1 덕질 몰입형(리텐션 코어), P2 취미 입문형(성장 볼륨), P3 오프모임 선호형(이벤트·안전 기능의 주 수요자), P4 온라인 대화 선호형(채팅·비동기 게임의 주 수요자). A3 핵심 루프는 P1·P4의 일일 루프를, A4 수익 모델은 P1(소모성)·P3(프로 티어) 결제 트리거를 기준으로 설계할 것.
2. **모드 분포 가정** — 친구 모드 시작 비율을 P2 90% / P4 70% / P1 60% / P3 40%로 가정. 온보딩(C3, E1)은 "친구 모드로 가볍게 시작 → 데이팅 모드 전환 유도"를 기본 동선으로 하고, 모드 전환 CTA는 매칭 만족 신호(첫 대화 10턴 이상 등) 이후에만 노출.
3. **최대 이탈 지점 2개** — (a) 매칭 대기 중 무응답 공백(모든 페르소나 공통): 오늘의 궁합 카드 + 취향 배틀로 "매칭 없어도 할 것"을 반드시 제공(A3·F1 필수 반영). (b) 첫 대화 첫 3턴: 첫 대화 제안 카드(§5-8)를 매칭 즉시 자동 노출하는 것을 Phase 1 범위로 유지할 것(D4·E3).
4. **매칭 정책 힌트** — 상호작용 매트릭스 결론: P1×P1(동일 팬덤), P3×P3, P2×P1(멘토-입문 구도, 친구 모드 한정)이 고만족 조합. P4에게 P3을 초기 추천하지 말 것(만남 압박으로 이탈 유발). D3 매칭 엔진은 "만남 성향 축" 점수 차이를 감점 요인으로 반영 권장.
5. **퀴즈 10문항 = 5축×2문항** — ① 몰입도(라이트↔헤비) ② 만남 성향(온라인↔오프라인) ③ 소통 템포(즉답↔느긋) ④ 탐험성(한우물↔잡식) ⑤ 관계 목적(친구↔연애 개방성). `quiz_questions.category` 값은 `immersion / meeting / tempo / explore / intent` 로 확정하며, D3 궁합 코사인 계산은 이 5축 벡터를 사용(D1 스키마 시드 데이터에 반영할 것). ⑤번 축 답변은 매칭 점수 외에 **모드 추천**(친구/데이팅)에도 사용.

## 1. 페르소나 4종

### P1. 덕질 몰입형 — "지우" (27, 여, IT 회사 QA)

**프로필**: 아이돌 팬덤 6년차 + 애니·웹툰 잡덕. 트위터(X) 알계 2개 운영, 콘서트·팝업스토어 원정 다님. 주변에 같은 최애를 파는 사람이 없어 덕질 얘기를 마음껏 못 함. 소개팅에서 "그런 거 왜 좋아해요?" 소리 듣고 현타.

- **핵심 JTBD**: "내 덕질을 설명하거나 변명하지 않아도 되는 사람을 찾을 때, **최애/작품 얘기로 바로 통하는 상대**를 만나서, 숨기던 자아 그대로 관계를 시작하고 싶다."
- **첫 주 시나리오**: D0 트위터 광고로 유입 → 온보딩에서 취미 태그·최애 입력에 15분 이상 공들임(덕질카드 = 자기표현 도구). D1~D3 매일 접속해 오늘의 궁합 카드 확인, 취향 배틀 전부 참여. D4 같은 팬덤 상대와 매칭 → 첫 대화 제안 카드("최애 컴백 무대 얘기") 클릭 → 대화 폭발. D7 스트릭 7일 달성, 대화 상대 2명 유지.
- **결제 의향**: **높음** (팬덤 소비 습관 有, 월 1~2만원 저항 없음). **트리거**: ① 같은 팬덤 상대가 "나를 좋아한 사람" 블러에 잡혔을 때(플러스 전환) ② 취향 배틀 결과 상세 열람 ③ 팬덤 이벤트(컴백·콘서트 시즌) 부스트.
- **모드 성향**: 친구 모드 60% 시작. "덕메 먼저, 연애는 통하면" — 데이팅 모드 전환 가능성 높은 이중 사용자.

### P2. 취미 입문형 — "민준" (24, 남, 대학원생)

**프로필**: 최근 클라이밍·보드게임에 입문. 아직 "덕후"라 하기엔 얕지만 같이 다닐 사람이 없어 흥미가 식을 위기. 당근·소모임 앱은 아저씨/아줌마 위주라 이탈. 데이팅 앱은 사진 스와이프가 부담스러워 삭제한 경험.

- **핵심 JTBD**: "새 취미를 시작했는데 같이 할 사람이 없을 때, **부담 없이 동행/대화 상대**를 구해서, 취미를 계속할 이유(그리고 어쩌면 인연)를 만들고 싶다."
- **첫 주 시나리오**: D0 친구 추천으로 가입, 취미 태그 3개만 겨우 채움(입력 부담 주의 — 온보딩에서 '입문' intensity 1~2 선택지가 심리적 허들을 낮춰야 함). D1~D2 추천 5명이 다 고수처럼 보여 위축 → 취향 배틀·궁합 퀴즈로 "실력 무관 궁합" 확인하고 안심. D5 '입문 환영' 태그 상대와 친구 모드 매칭, 첫 대화 제안 카드("토요일 암장 같이?")로 약속. D7 재접속률은 대화 성사 여부에 전적으로 좌우.
- **결제 의향**: **낮음~중간** (학생 예산). **트리거**: ① 첫 오프 동행이 성사된 직후의 만족 피크(플러스 1개월 체험가) ② 되돌리기(실수로 넘긴 상대) 1회성 욕구. 구독보다 소모성·저가 진입 상품이 유효.
- **모드 성향**: 친구 모드 90%. 데이팅 모드는 서비스 신뢰가 쌓인 뒤(3~4주차) 전환 검토. **친구 모드 경험이 곧 데이팅 전환 퍼널**인 대표 페르소나.

### P3. 오프모임 선호형 — "서연" (31, 여, 마케터)

**프로필**: 러닝 크루 + 카페투어 + 전시. 만나서 뭘 해야 관계가 시작된다는 주의. 채팅만 길어지는 앱은 "말만 하다 끝난다"며 삭제. 다만 낯선 사람과의 1:1 첫 만남은 안전이 걱정 — 인증·공개 장소·모임 형태를 선호.

- **핵심 JTBD**: "채팅 핑퐁에 지쳤을 때, **검증된 사람과 실제 활동 약속**으로 빨리 넘어가서, 만나서 자연스럽게 사람을 판단하고 싶다."
- **첫 주 시나리오**: D0 가입 즉시 본인인증까지 완료(인증 레벨 = 신뢰 시그널로 인식). D1 추천 상대의 활동 시간대 겹침을 가장 유심히 봄. D3 매칭 → 첫 대화 제안 카드("이번 주 토요일 홍대 보드게임카페 어때요?")가 정확히 니즈 적중, 3일 내 약속 확정. D6 첫 만남(공개 장소) → 만남 후 앱 내 후기/안전 체크인이 있으면 신뢰 급상승. 주간 취미 이벤트(오프모임) 존재를 발견하면 락인.
- **결제 의향**: **중간~높음** (30대 초, 시간 > 돈). **트리거**: ① **이벤트 우선 참가(프로 티어의 킬러 혜택)** ② 활동 시간대 맞는 상대 우선 노출 ③ 무한 채팅 스킵 = 추천 수 확대. 프로 티어의 핵심 타깃.
- **모드 성향**: 데이팅 모드 60% 직행(목적 명확). 단, 데이팅 모드도 "모임에서 자연스럽게"를 선호 — 그룹 이벤트 → 1:1 전환 동선이 중요.

### P4. 온라인 대화 선호형 — "하늘" (22, 논바이너리 표기 선택 가능 가정 / 여, 휴학생·프리랜서 일러스트레이터)

**프로필**: 웹툰·게임(발로란트, 원신)·버튜버. 디스코드에서는 수다쟁이지만 오프라인 만남은 에너지 소모가 큼. 밤 시간대 활동. 외모 노출·즉각적 만남 압박이 있는 앱은 즉시 삭제. 사진보다 취향으로 평가받고 싶음.

- **핵심 JTBD**: "얼굴·만남 부담 없이, **밤에 편하게 떠들 취향 맞는 대화 상대**를 만들어서, 내 페이스대로 관계 깊이를 정하고 싶다."
- **첫 주 시나리오**: D0 "첫 화면이 사진이 아니라 덕질카드"라는 포지셔닝에 반응해 가입. 사진 업로드는 최소(1장, 뒷모습/일러스트 아님 주의 — 검수 정책과 충돌 지점). D1~D7 매일 밤 11시~새벽 1시 접속: 궁합 카드 확인 → 취향 배틀 → 비동기 덕질 퀴즈 대전. D4 매칭 후 텍스트 대화가 길게 이어짐(일 30턴+). 만남 제안 카드는 무시하고 "온라인으로 같이 게임" 류 제안만 클릭. D7 대화 상대 1명과 디코 이동 욕구 발생(연락처 마스킹 3일 규칙과 접점).
- **결제 의향**: **낮음** (수입 불규칙) 그러나 소액 소모성엔 관대(게임 과금 습관). **트리거**: ① 슈퍼라이크 팩(취향 저격 상대 발견 시) ② 광고 제거 목적의 플러스 ③ 퀴즈 대전 관련 소모성 아이템(F그룹 설계 시 고려).
- **모드 성향**: 친구 모드 70%. 데이팅 모드로 가더라도 "온라인 장기 대화 → 신뢰 후 만남" 경로. 만남 재촉 UX는 이 페르소나에게 역효과.

| **P1 몰입형** | ◎ 같은 팬덤이면 최상. 다른 팬덤이면 ○(덕질 문법은 통함) | ○ P1이 가르쳐주는 구도가 즐거움(친구 모드 한정, 데이팅에선 온도차 위험) | ○ 팬덤 오프행사(콘서트·팝업) 동행이면 ◎ | ◎ 같은 작품/게임이면 밤 대화 궁합 최상 |
| **P2 입문형** | ○ 멘토를 얻음 — 단 P1이 부담스러워하지 않게 '입문 환영' 의사 확인 필요 | ○ 서로 편하지만 활동 추진력 부족 → 제안 카드가 견인해야 함 | ◎ P3이 리드해줘서 P2의 "같이 갈 사람" 니즈 정확히 해소 | △ 온라인 대화만으로는 P2의 동행 니즈 미충족 |
| **P3 오프모임** | ○ 활동 겹치면 좋으나 P1의 온라인 덕질 비중에 답답할 수 있음 | ◎ 리드하는 역할에 만족 | ◎ 시간대만 맞으면 최고 궁합, 약속 성사율 최상 | △ **비추천 조합** — 만남 재촉 vs 회피로 상호 불만. 초기 추천에서 배제 권장 |
| **P4 온라인** | ◎ 텍스트 덕질 수다 최상 | △ P2는 결국 오프 동행을 원함 | △ 위와 동일 | ◎ 페이스 동일, 비동기 게임 궁합 최상 — 단 만남 전환율은 낮으니 KPI 분리 필요 |

**D3 반영 권장**: 동일 페르소나 축(특히 만남 성향·소통 템포) 근접 매칭을 기본으로 하되, P2×P1·P2×P3 같은 **보완 조합은 친구 모드에서 가중**, 데이팅 모드에서는 성향 근접을 우선. P3×P4는 성향 축 거리 감점으로 자연 배제.

**설계 규칙 제안**
- 각 문항 `options`는 4지선다(양극 2 + 중간 2)로 벡터값 -1.0 / -0.33 / +0.33 / +1.0 부여, `weight`는 기본 1.0에 `meeting`·`intent` 축만 1.2(이탈·불만과 직결되는 축이므로).
- `intent` 축 결과는 궁합 점수 외에 온보딩 마지막의 **모드 기본값 추천**(친구/데이팅)에 사용하되 강제하지 않음.
- 문항 카피는 정답 없음·재미 톤 유지(§0-정책: 진단·확정 표현 금지 원칙과 동일 기조), 결과 화면에 "궁합은 재미와 추천용" 고지.
