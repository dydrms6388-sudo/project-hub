# {{SERVICE_NAME}} 환불정책

이 환불정책은 {{COMPANY_NAME}}(이하 "회사")가 제공하는 "{{SERVICE_NAME}}" 유료서비스의 청약철회·환불 기준을 정합니다. 이용약관 제18조(청약철회 및 환불)의 세부 기준이며, 「전자상거래 등에서의 소비자보호에 관한 법률」(이하 "전자상거래법")에 따릅니다. 결제 화면에 표시된 가격·수량·유효기간·사용 개시 시점은 이 정책과 함께 적용됩니다.

## 1. 한눈에 보기

| 항목 | 기준 |
|---|---|
| 청약철회 기간 | **결제일로부터 7일 이내** |
| 구독 환불액 | 월 요금 − (월 요금 × 사용일수 ÷ 해당 달 일수) |
| 아이템 환불액 | 묶음 가격 − (단가 × 사용 수량) |
| 부스트 | 발동 전 전액 / **발동 후 0원**(발동 = 전량 사용) |
| 궁합 카드 리필(당일 소멸) | 미사용 상태로 당일 요청 시 전액 / 1장이라도 사용 시 불가 |
| 7일 경과 후 | 원칙적으로 불가(잔여 혜택 유지). 서비스 장애·중복 결제·미성년 결제는 전액 |
| 처리 기한 | 접수 후 **3영업일 이내** 결제수단으로 환불 |
| 신청 방법 | 설정 > 결제 내역 > [환불 요청] (예상 환불액 즉시 표시) |
| 앱 마켓 결제 | Google Play·App Store 환불 정책·절차가 우선 |

## 2. 청약철회 기간과 디지털콘텐츠 고지
1. 회원은 결제일로부터 **7일 이내** 청약을 철회할 수 있습니다(전자상거래법 제17조 제1항).
2. 유료서비스는 결제 즉시 제공이 개시되는 **디지털콘텐츠**입니다. 전자상거래법 제17조 제2항 제5호에 따라 제공이 개시된 부분은 청약철회가 제한되며, 회사는 이 사실을 결제 화면에 표시합니다. 다만 구독과 아이템은 **가분적 디지털콘텐츠**로서 아직 제공되지 않은 부분(남은 기간·미사용 수량)에 대해서는 청약철회를 인정하고 아래 계산식으로 사용분을 차감한 뒤 환불합니다.
3. 사용 개시 시점
   - 구독: 결제 완료 시점(결제 당일을 사용 1일로 계산)
   - 슈퍼라이크·되돌리기: 각 1개를 실제 사용한 시점
   - 부스트: **발동 버튼을 누른 시점**(발동 후 남은 시간과 관계없이 전량 사용)
   - 궁합 카드 리필: 1장을 뽑은 시점

## 3. 계산식

### 3.1 구독 (플러스·프로 월 구독)
```
사용일수 U = max(1, floor((요청일 − 결제일) / 1일) + 1)    -- 결제 당일도 1일 사용
해당 달 일수 D = 결제일이 속한 달의 총 일수 (28~31)
차감액 = round(월 요금 F × U ÷ D)
환불액 = F − 차감액
```
- 결제일로부터 7일 이내 요청 시 위 공식을 적용합니다. 7일 초과 시 원칙적으로 환불되지 않으며 결제된 기간이 끝날 때까지 혜택이 유지됩니다.
- 구독 기간 중 지급된 주간 슈퍼라이크 등 구독 혜택은 이미 "사용일수"에 포함된 것으로 보고 별도로 차감하지 않습니다(이중 차감 없음).
- 환불 승인 시 구독은 즉시 종료되어 무료 회원으로 전환되며, 미사용 주간 혜택은 소멸합니다.
- 갱신 결제분(2회차 이후)도 각 결제일을 기준으로 동일하게 적용됩니다.

### 3.2 소모성 아이템 (슈퍼라이크·되돌리기 이용권 등 수량형)
```
단가 = 묶음 가격 F ÷ 수량 Q
차감액 = round(단가 × 사용 수량 u)
환불액 = F − 차감액
```
- 유효기간 만료로 소멸한 수량은 차감하지 않습니다(7일 내에는 만료가 발생하지 않도록 유효기간은 90일 이상이거나 당일 소멸형입니다).
- 사용 순서는 만료 임박분 → 무료(퀘스트 보상)분 → 구매분이므로, 환불 시 구매분이 먼저 회수됩니다. 이미 잔액이 회수 가능 수량보다 적은 경우 환불액은 **단가 × 실제 회수 가능 수량**으로 재계산됩니다.
- 환불 승인 시 미사용 구매분은 즉시 회수됩니다.

### 3.3 부스트 (1시간)
```
발동 전: 환불액 = 구매 가격 전액
발동 후: 환불액 = 0원  (발동 = 사용 개시 = 전량 사용)
```
- 발동 후 남은 시간(예: 40분)과 관계없이 환불되지 않습니다. 결제 화면과 발동 확인 화면에 이 사실이 표시됩니다.
- 부스트 발동 중 회사의 서버 장애로 노출 가중이 실제로 적용되지 않았음이 확인되면 전액 환불합니다(사유: 서비스 장애).

### 3.4 궁합 카드 리필 (당일 소멸)
- 미사용 상태로 **구매 당일** 요청 시 전액 환불합니다.
- 1장이라도 사용한 경우 환불되지 않습니다.
- 당일 07:00(KST) 일일 경계에 소멸하는 상품이므로 다음 날 이후 요청은 불가합니다.

## 4. 계산 예시

| # | 상황 | 계산 | 환불액 |
|---|---|---|---|
| 1 | **플러스 구독(₩9,900) 9월 1일 결제 → 9월 3일 환불 요청** | U = 3일, D = 30일 → 차감 round(9,900 × 3 ÷ 30) = ₩990 | **₩8,910** (즉시 무료 전환, 미사용 주간 혜택 소멸) |
| 2 | **슈퍼라이크 5개 묶음(₩4,900) 중 2개 사용, 결제 5일째 요청** | 단가 4,900 ÷ 5 = ₩980 → 차감 980 × 2 = ₩1,960 | **₩2,940** (미사용 3개 회수) |
| 3 | **부스트(₩3,900) 구매 후 발동, 40분 경과, 당일 요청** | 발동 = 전량 사용 → 차감 ₩3,900 | **₩0** (단, 발동 중 서버 장애가 확인되면 ₩3,900 전액) |

## 5. 7일이 지난 뒤에도 전액 환불되는 경우
다음 사유는 청약철회 기간과 사용분 차감 규칙을 적용하지 않고 전액 환불합니다.

| 사유 | 설명 |
|---|---|
| 서비스 장애 | 회사 귀책으로 결제한 혜택이 정상 제공되지 않은 경우(로그로 확인) |
| 중복 결제·오과금 | 같은 상품이 이중 결제되었거나 표시 가격과 다르게 청구된 경우 |
| 미성년 결제 | 결제자가 만 19세 미만으로 확인된 경우(계정은 청소년보호정책에 따라 정지) |

## 6. 환불이 되지 않는 경우
1. 결제일로부터 7일이 지난 구독·아이템(제5항 사유 제외). 잔여 기간·잔여 수량의 혜택은 유지됩니다.
2. 발동한 부스트, 1장 이상 사용한 궁합 카드 리필.
3. 퀘스트·스트릭 등 무료로 획득한 아이템.
4. **이용약관 위반으로 이용정지(3일 이상) 또는 영구 이용정지된 회원의 잔여 구독 기간·미사용 아이템.** (변호사 검토)
5. 회원이 탈퇴한 뒤 남은 구독 기간·아이템(탈퇴 전 환불 신청 필요. 탈퇴만으로 환불 신청이 되지 않습니다).

## 7. 신청 및 처리 절차
1. 설정 > 결제 내역에서 해당 결제의 **[환불 요청]**을 누르면 위 계산식에 따른 **예상 환불액이 즉시 표시**됩니다. 이메일 문의 없이 앱 안에서 접수됩니다.
2. 사유(단순 변심 / 서비스 장애 / 중복 결제 / 미성년 결제 / 기타)를 선택하고 제출합니다.
3. 회사는 접수 후 **3영업일 이내**에 결제에 사용한 수단으로 환불(부분 취소)을 실행합니다. 카드사·결제사 사정에 따라 실제 입금·취소 반영까지 3~7영업일이 추가로 걸릴 수 있습니다.
4. 결제수단으로 환불이 불가능한 경우(카드 해지 등) 회원과 협의한 방법으로 환불합니다.
5. 회사는 환불 계산에 사용한 값(사용일수·달 일수·사용 수량·단가)을 분쟁 대비를 위해 5년간 보관합니다.
6. 환불 후 30일 내 같은 상품을 재구매하는 경우 환불 이력은 운영 참고용으로만 기록되며, 이를 이유로 구매를 거부하거나 제재하지 않습니다.

## 8. 구독 해지와 환불의 차이
- **해지**: 설정 > 구독 관리 > [구독 해지] → 확인 1회. 다음 갱신 결제가 중단되고, 이미 결제된 기간이 끝날 때까지 혜택이 유지됩니다. 해지 자체로는 환불되지 않습니다.
- **환불(청약철회)**: 결제일로부터 7일 이내 요청 시 사용분을 차감하고 돌려받으며 구독은 즉시 종료됩니다.
- 갱신 결제 7일 전에 이메일·앱 알림으로 갱신 예정을 안내하므로, 갱신을 원하지 않으면 알림 후 해지하면 됩니다.

## 9. 앱 마켓(Google Play·App Store) 결제
1. 모바일 앱에서 앱 마켓의 인앱 결제로 구매한 경우 **해당 마켓의 환불 정책과 절차가 우선** 적용되며, 회사가 직접 환불을 실행할 수 없는 경우가 있습니다.
2. 회사는 앱 내 결제 내역 화면에서 마켓 환불 요청 경로(Google Play 주문 내역, App Store "문제 신고")로 바로 연결되는 링크를 제공합니다.
3. 마켓 정책에 따라 환불이 거부된 경우라도 제5항의 사유(서비스 장애·중복 결제·미성년 결제)에 해당하면 회사에 문의하시면 별도로 처리합니다.
4. 웹과 앱의 가격이 다른 경우 앱 내에 그 사실을 표시합니다.
