# {{SERVICE_NAME}} 개인정보처리방침

{{COMPANY_NAME}}(이하 "회사")는 「개인정보 보호법」 제30조에 따라 정보주체의 개인정보를 보호하고 이와 관련한 고충을 신속하고 원활하게 처리할 수 있도록 다음과 같이 개인정보처리방침을 수립·공개합니다. 이 방침은 회사가 제공하는 "{{SERVICE_NAME}}" 서비스(`{{DOMAIN}}` 및 모바일 앱, 이하 "서비스")에 적용됩니다.

**요약 (법적 효력은 본문에 따릅니다)**
- 만 19세 이상만 가입할 수 있으며, 본인인증 결과 중 **성명은 저장하지 않습니다.**
- **GPS·IP 기반 위치정보를 수집하지 않습니다.** 위치는 회원이 직접 선택한 시/군/구만 저장합니다.
- 채팅 원문은 발신자 본인과 신고 처리 운영자만 열람할 수 있습니다.
- 개인정보를 제3자에게 판매·제공하지 않습니다(법령상 요청 제외).
- 탈퇴 후 7일의 유예기간을 거쳐 삭제되며, 법령상 보존 항목과 신고·제재 기록은 정해진 기간 동안 보관됩니다.

## 제1조 (개인정보의 처리 목적)
회사는 다음의 목적을 위해 개인정보를 처리합니다. 처리하는 개인정보는 다음 목적 이외의 용도로는 이용되지 않으며, 이용 목적이 변경되는 경우 「개인정보 보호법」 제18조에 따라 별도의 동의를 받는 등 필요한 조치를 이행합니다.

| 목적 | 세부 내용 |
|---|---|
| 회원 가입 및 관리 | 가입 의사 확인, 만 19세 이상 연령 확인, 본인 식별·인증, 중복 가입 및 제재 회피 방지, 계정 유지·관리, 각종 고지·통지, 탈퇴 처리 |
| 서비스 제공 | 덕질 카드(취미 프로필) 표시, 궁합 퀴즈·취미·활동 시간대 기반 추천 생성, 좋아요·매칭, 채팅 및 제안 카드, 게임·퀘스트, 이벤트 참가 |
| 안전 및 신뢰 확보 | 사진 검수, 연락처 마스킹, 사기·성희롱·미성년 의심 등 위험 신호 자동 탐지, 신고·차단 처리, 증거 보존, 제재·이의신청 처리, 부정 이용 방지 |
| 유료서비스 제공 | 구독·아이템 구매, 결제 처리, 자동갱신 통지, 환불·청약철회 처리, 영수증 발급, 결제 분쟁 대응 |
| 고객 문의 대응 | 문의 접수·확인·회신, 개인정보 열람·정정·삭제·다운로드 요청 처리 |
| 서비스 개선 | 가명·익명 처리된 이용 통계 분석, 장애 대응, 기능 개선 |
| 알림 발송 | 추천 도착·매칭·답장·검수 결과 등 서비스 알림, (동의 시) 광고성 정보 전송 |

### 2.2 서비스 이용 과정에서 자동으로 생성·수집되는 항목
- 접속 로그(IP 주소, 접속 일시, 기기·브라우저 정보), 서비스 이용 기록(화면 이동·기능 사용 이벤트, 회원 식별자는 솔트 해시로 대체), 오류 로그
- 쿠키·로컬 스토리지(제12조 참조)
- 자동 탐지 규칙 적용 결과(메시지별 규칙 식별자, 사람의 판정 전까지 제재 근거로 단독 사용하지 않음)

### 2.3 수집하지 않는 항목
- **GPS·기지국·Wi-Fi·IP 기반 위치정보** (위치는 회원이 직접 선택한 시/군/구만 저장)
- 본인인증 결과의 **성명**, 주민등록번호, 신분증 이미지
- 결제 카드번호·계좌번호
- 기기 연락처(향후 "아는 사람 차단" 기능 도입 시 기기에서 해시 처리한 값만 별도 동의 후 수집 예정)
- 광고 식별자(ADID/IDFA)는 모바일 앱 출시 시 별도 동의를 받은 후에만 수집하며, 도입 시 본 방침을 개정합니다.

### 2.4 만 14세 미만 및 만 19세 미만
회사는 만 14세 미만 아동 및 만 19세 미만 청소년의 개인정보를 수집하지 않습니다. 가입 시 생년월일로 만 19세 미만이 확인되면 이용계약이 체결되지 않으며, 입력된 정보는 30일 후 삭제됩니다. 본인인증 결과 만 19세 미만으로 확인된 경우 즉시 계정을 영구 이용정지하고 게시물을 삭제하며, 재가입 방지를 위한 CI 해시만 보관합니다.

## 제3조 (개인정보의 처리 및 보유기간)
회사는 법령에 따른 보유기간 또는 정보주체로부터 동의받은 보유기간 내에서 개인정보를 처리·보유합니다.

### 3.1 회원 탈퇴 시 처리 (탈퇴 신청 후 7일 유예기간 경과 시 기준)

| 항목 | 처리 | 보유기간 및 근거 |
|---|---|---|
| 프로필(닉네임·자기소개·취미·퀴즈 응답·활동 시간대·지역·모드) | 즉시 삭제 | — |
| 사진(원본) | 즉시 삭제 | — |
| 계정(휴대폰번호) | 즉시 삭제 | 휴대폰번호 해시만 30일 보관(재가입 어뷰즈 방지) |
| 본인인증 정보(CI/DI 해시·생년월일·성별) | 보관 후 삭제 | **1년** (중복가입·제재 회피 방지). 영구 이용정지자는 **5년** |
| 채팅 메시지 | 상대 화면에 "탈퇴한 사용자"로 표시 | 상대방 탈퇴 또는 매칭 종료 후 **90일** 뒤 삭제 (상대방의 열람권 보장) |
| 좋아요·매칭·추천 이력 | 즉시 삭제 | 매칭은 상대 화면 표시용으로 90일 후 삭제 |
| 신고 기록 및 증거 스냅샷(신고자·피신고자로서) | 보존 | 아래 3.2 표에 따름. **탈퇴와 무관하게 유지** |
| 제재 기록 | 보존 | 아래 3.2 표에 따름. 회원 식별자는 CI 해시로 대체 |
| 구독·아이템 원장·결제·환불 기록 | 보존 | **5년** (「전자상거래 등에서의 소비자보호에 관한 법률」) |
| 감사 로그(운영자 조치 기록) | 보존 | **1년** |
| 게임·퀘스트·이벤트 참가 기록 | 즉시 삭제 | — |
| 접속 로그(IP·기기) | 보존 | **3개월** (「통신비밀보호법」) |
| 푸시 구독 정보 | 즉시 삭제 | — |
| 만 19세 미만으로 가입 차단된 정보 | 삭제 | **30일** |

- 탈퇴 신청 즉시 로그아웃되고 다른 회원에게 노출되지 않으며, **7일 유예기간** 내 재로그인 시 탈퇴가 취소됩니다. 유예기간 경과 후 일 1회 삭제 배치가 실행됩니다.
- 활성 제재 중 탈퇴하더라도 제재 기록과 CI 해시는 유지되어 재가입 시 적용됩니다.

### 3.2 신고 증거 및 제재 기록 보유기간

| 상황 | 보유기간 |
|---|---|
| 신고가 기각(dismissed)으로 종결 | 종결 후 **90일** |
| 신고가 확정(confirmed)으로 종결 | 종결 후 **180일** |
| 영구 이용정지 확정 | **5년** (재가입 방지·분쟁 대응) |
| 수사기관·법원·분쟁조정 절차 진행 중(legal hold) | 절차 종료 시까지, 종료 후 90일 |

증거 스냅샷은 신고 처리 목적의 운영자(moderator/admin)만 열람할 수 있으며 모든 열람은 감사 로그에 기록됩니다.

## 제4조 (개인정보의 제3자 제공)
1. 회사는 정보주체의 개인정보를 제1조의 목적 범위 내에서만 처리하며, **정보주체의 개인정보를 제3자에게 제공하지 않습니다.**
2. 다음 각 호의 경우는 예외로 합니다.
   1. 정보주체가 사전에 별도로 동의한 경우
   2. 법령에 특별한 규정이 있거나 법령상 의무를 준수하기 위해 불가피한 경우(수사기관·법원의 적법한 영장·요청 등)
   3. 정보주체 또는 제3자의 급박한 생명·신체·재산상 이익을 위해 필요하다고 인정되는 경우
3. 회원 간 서비스 이용 과정에서 다른 회원에게 표시되는 정보(닉네임, 연령대, 시/군/구, 덕질 카드, 승인된 사진, 인증 마크, 부스트 사용 여부)는 서비스 제공 목적의 처리이며 제3자 제공에 해당하지 않습니다. 생년월일 원본·휴대폰번호·성별(친구 모드)·본인인증 정보는 다른 회원에게 표시되지 않습니다.

## 제7조 (정보주체와 법정대리인의 권리·의무 및 행사방법)
1. 정보주체는 회사에 대해 언제든지 다음의 권리를 행사할 수 있습니다.
   1. 개인정보 열람 요구
   2. 오류 등이 있을 경우 정정 요구
   3. 삭제 요구
   4. 처리정지 요구
   5. 동의 철회(회원 탈퇴)
   6. 개인정보 전송(다운로드) 요구
2. 권리 행사 방법
   - 열람·정정: 설정 > 프로필 편집에서 직접 확인·수정할 수 있습니다. 본인인증으로 확인된 생년월일·성별은 재인증을 통해서만 정정됩니다.
   - 삭제·동의 철회: 설정 > 탈퇴(7일 유예 후 삭제)
   - 처리정지: 설정 > 휴면 전환(추천·노출·알림 중단) 또는 아래 문의 채널
   - 다운로드: 문의 채널로 요청 시 회사는 **10일 이내**에 다음 항목을 JSON 파일로 이메일 전달합니다. 프로필, 취미·최애·퀴즈 응답, 활동 시간대, 사진, 본인이 보낸 좋아요, 매칭 목록(상대는 닉네임만), **본인이 보낸 메시지 원문**, 본인이 제출한 신고 목록(결과 포함, 피신고자 정보 제외), 본인에게 내려진 제재 목록, 결제·구독 내역, 이벤트 참가·게임 기록. 타인의 메시지·사진, 추천 점수 내부값, 탐지 규칙 상세, 타인이 제출한 신고는 제외됩니다. 앱 내 자동 다운로드 기능은 추후 제공 예정입니다.
   - 문의 채널: {{PRIVACY_OFFICER_EMAIL}} 또는 앱 내 문의하기. 회사는 「개인정보 보호법 시행령」 제41조에 따라 요청을 받은 날로부터 10일 이내에 조치합니다.
3. 권리 행사는 정보주체의 법정대리인이나 위임을 받은 자 등 대리인을 통해 할 수 있으며, 이 경우 「개인정보 처리 방법에 관한 고시」 별지 제11호 서식에 따른 위임장을 제출해야 합니다.
4. 열람·처리정지 요구는 「개인정보 보호법」 제35조 제4항, 제37조 제2항에 따라 제한될 수 있으며, 삭제 요구는 다른 법령에서 수집 대상으로 명시된 개인정보(제3조 3.2·3.3의 보존 항목)에 대해서는 제한됩니다. 이 경우 회사는 그 사유를 지체 없이 알립니다.
5. 회사는 권리 행사 요구자가 본인 또는 정당한 대리인인지 확인합니다.

## 제8조 (개인정보의 파기 절차 및 방법)
1. 회사는 보유기간의 경과, 처리 목적 달성 등 개인정보가 불필요하게 되었을 때 지체 없이 해당 개인정보를 파기합니다.
2. 정보주체로부터 동의받은 보유기간이 경과하거나 처리 목적이 달성되었음에도 다른 법령에 따라 보존해야 하는 경우 해당 개인정보를 별도의 데이터베이스(테이블)로 옮기거나 접근 권한을 분리하여 보존합니다.
3. 파기 절차: 파기 사유가 발생한 개인정보를 선정하고, 개인정보보호책임자의 승인 하에 일 1회 자동 삭제 배치가 실행됩니다. 삭제 실행 사실은 내용을 제외하고 감사 로그에 기록됩니다.
4. 파기 방법: 전자적 파일은 복구·재생이 불가능한 방법으로 영구 삭제하며, 클라우드 저장소 객체는 삭제 API를 통해 제거합니다. 종이 문서는 보관하지 않습니다.

## 제9조 (개인정보의 안전성 확보조치)
회사는 「개인정보 보호법」 제29조에 따라 다음과 같은 조치를 취하고 있습니다.
1. 관리적 조치: 내부관리계획 수립·시행, 개인정보 취급자 최소화 및 교육, 운영자 권한 2단계 분리(moderator/admin)
2. 기술적 조치
   - 데이터베이스 행 수준 보안(RLS) 전면 적용: 본인 데이터만 쓰기 가능, 매칭 상대는 프로필 읽기만, 차단 관계는 상호 비가시
   - 채팅 원문은 발신자와 운영자만 접근 가능하도록 컬럼 단위 접근 제어
   - 본인인증 CI/DI는 솔트 해시로만 저장, 성명 미저장, 생년월일 원본 접근 제한
   - 전송 구간 암호화(TLS), 저장 데이터 암호화(클라우드 제공자 기본 암호화)
   - 서비스 키·비밀값은 서버 환경에서만 사용하며 클라이언트에 포함하지 않음
   - 사진 업로드 시 EXIF 메타데이터(촬영 위치 포함) 제거, 파일 형식 검증
   - 접속 기록 보관(3개월) 및 위·변조 방지, 운영자의 증거 열람·판정 감사 로그 기록
   - 분석 이벤트는 회원 식별자를 해시 처리하고 메시지 원문을 포함하지 않음
3. 물리적 조치: 클라우드 제공자의 데이터센터 물리 보안 및 접근 통제에 의존하며, 회사는 별도 서버실을 운영하지 않습니다.

## 제12조 (개인정보 자동 수집 장치의 설치·운영 및 거부)
1. 회사는 로그인 상태 유지 및 서비스 제공을 위해 쿠키(cookie)와 브라우저 로컬 스토리지를 사용합니다.
   - 인증 세션 쿠키: 로그인 유지(필수). 거부 시 서비스 이용 불가
   - 설정 저장: 테마·알림 설정 등 이용자 편의(선택)
   - 트래픽 분석(Vercel Analytics): 페이지 방문 통계, 개인 식별 불가한 형태로 집계
2. 회원은 브라우저 설정(도구 > 인터넷 옵션 > 개인정보 등)에서 쿠키 저장을 거부하거나 삭제할 수 있습니다. 다만 필수 쿠키를 거부하면 로그인이 유지되지 않습니다.
3. 회사는 웹 서비스에서 행태정보 기반 맞춤형 광고를 위한 제3자 쿠키를 사용하지 않습니다. 모바일 앱에서 광고 식별자를 이용한 광고를 도입하는 경우 앱 첫 실행 시 별도 동의를 받고 본 방침을 개정합니다.
