# {{SERVICE_NAME}} 커뮤니티 가이드라인

{{SERVICE_NAME}}는 "같은 걸 좋아하는 사람이랑 만나는" 곳입니다. 서로의 취미를 존중하고 안전하게 대화할 수 있도록 아래 규칙을 지켜 주세요. 이 가이드라인은 이용약관 제21조(금지행위)·제23조(제재)·제24조(이의신청)의 구체적 기준이며, 약관과 충돌하는 경우 이 가이드라인이 우선합니다.

## 1. 우리가 지키는 것

- **본인으로 참여합니다.** 실제 나이·성별·취미, 내 얼굴 사진. 캐릭터·취미 사진은 보조 사진으로만.
- **상대가 원하지 않는 이야기는 하지 않습니다.** 성적인 말, 외모 평가, 개인정보 캐묻기 모두 포함입니다.
- **돈 이야기는 하지 않습니다.** 송금·투자·상품권 요구는 대화가 아니라 신호입니다.
- **여기서 충분히 대화한 뒤에 옮깁니다.** 매칭 후 3일 동안은 연락처가 자동으로 가려집니다.
- **불편하면 신고·차단합니다.** 상대에게 알림이 가지 않고, 24시간 안에 확인합니다.

### 프로필 사진 기준
- 대표 사진: 얼굴이 명확히 보이는 본인 사진만 승인됩니다. 마스크·선글라스로 식별이 어렵거나 뒷모습·풍경·단체 사진은 대표 사진으로 승인되지 않습니다.
- 보조 사진: 취미 사진, 캐릭터, 그림도 가능합니다.
- 반려 사유: 얼굴 없음 / 본인 아님 / 노출 / 연락처·SNS·QR 포함 / 미성년으로 보임 / 단체 사진 / 저화질·과도한 필터
- 승인 전까지 사진은 본인에게만 보이며, 24시간 안에 확인합니다.

### 채팅에서 자동으로 적용되는 보호
- 매칭 후 72시간 동안 휴대폰번호·메신저 ID·SNS·링크·이메일·계좌번호는 `[연락처 숨김]`으로 가려집니다(양쪽 모두 사진인증이 완료된 뒤 72시간이 지나면 해제).
- 금전·투자 관련 표현이 감지되면 상대 화면에 주의 배너가 표시됩니다.
- 채팅 이미지는 양쪽 사진인증 + 매칭 24시간 후부터 보낼 수 있고, 받는 사람 화면에는 흐리게 표시된 뒤 선택해서 봅니다.

## 3. 제재 등급표

### 3.1 등급

| 등급 | 명칭 | 효과 | 판정 |
|---|---|---|---|
| 1 | 경고 | 앱 내 경고(확인 필수) + 이메일. 기능 제한 없음 | 자동/운영자 |
| 2 | 채팅 제한 24시간 | 메시지 전송 불가(읽기 가능), 새 좋아요 불가 | 자동/운영자 |
| 3 | 이용정지 3일 | 로그인 시 정지 화면만. 추천·프로필 비노출 | 운영자 |
| 4 | 이용정지 7일 | 3등급과 동일 | 운영자(관리자) |
| 5 | 이용정지 30일 | 4등급 + 활성 매칭 일시 중단 | 운영자(관리자) |
| 6 | 영구 이용정지 | 계정 영구 정지, 본인인증 기준 재가입 차단, 구독 즉시 종료·환불 없음 | 운영자(관리자). 미성년 확정만 자동 |

- 자동 제재는 2등급(채팅 제한 24시간)까지만 적용되며, 3등급 이상은 반드시 사람이 확인한 뒤 결정합니다.
- 신고 접수 즉시 적용될 수 있는 임시 조치: 메시지 전달 보류, 사진 비노출, 프로필 비노출, 재인증 요구. 신고가 기각되면 즉시 해제됩니다.

### 3.3 누적 규칙
- 서로 다른 신고자 3명이 30일 안에 같은 회원을 신고하면(기각 제외) 자동으로 채팅 제한 24시간이 적용되고 우선 검토됩니다.
- 서로 다른 신고자 5명이 90일 안에 신고하면 운영자 판정 전까지 프로필이 비노출됩니다.
- 3등급 이상 제재가 12개월 안에 3회 확정되면 영구 이용정지를 검토합니다.
- 경고(1등급) 3회 누적 시 자동으로 채팅 제한 24시간이 적용됩니다.
- 누적은 탈퇴·재가입과 무관하게 본인인증 기준으로 이어집니다.
- 같은 매칭에서 연락처 마스킹 우회를 3회 시도하면 경고 배너와 함께 "외부 연락 유도" 신고가 자동 접수됩니다.

## 4. 안전 팁

### 처음 만나는 날
- 사람 많은 공개 장소에서, 낮이나 이른 저녁에 만나요.
- 친구에게 누구를 어디서 만나는지 알려 두세요.
- 이동은 각자, 첫 만남에 술은 가볍게.
- 뭔가 이상하면 그냥 나와도 괜찮아요. 이유를 설명할 필요 없어요.

### 돈 이야기가 나오면
- 송금, 투자 앱 설치, 상품권·기프티콘 코드, "급한 사정"은 전부 거절하세요. 매칭 상대에게 돈을 보내지 마세요.
- 의심되면 대화 중간에라도 바로 [신고]. 대화 기록은 자동으로 첨부됩니다.

### 개인정보
- 집 주소, 직장, 실명, 신분증, 계좌번호는 알려주지 않아도 됩니다. 요구 자체가 신고 사유입니다.
- 연락처는 매칭 3일 뒤부터 주고받을 수 있어요. 그 전엔 여기서 충분히 대화해 보세요.

### 사진
- 상대 사진을 저장·캡처해 외부에 공유하지 마세요. 상대가 보낸 사진을 동의 없이 유포하면 형사 처벌 대상입니다.
- 채팅 이미지는 흐리게 도착합니다. 보고 싶지 않으면 열지 않아도 됩니다.

## 5. 신고 방법
1. 상대 프로필 또는 채팅 화면 상단 메뉴 > **[신고]**
2. 사유 14개 중 1개 선택 + 내용 서술(선택, "기타"는 필수, 500자)
3. 최근 대화 50개·프로필·사진 등 증거는 **자동으로 첨부**됩니다. 직접 캡처할 필요 없습니다.
4. 제출 후 "차단도 할까요?"가 기본 체크되어 있습니다. 차단하면 즉시 서로 보이지 않고 상대에게 알림이 가지 않습니다.
5. 회사는 접수 후 **24시간 안에** 확인하며(사기·미성년·불법촬영물·협박·스토킹은 1시간 목표), 처리 결과는 "조치가 완료되었어요" 수준으로 알려드립니다. 신고자 정보는 상대에게 절대 공개되지 않습니다.
6. 같은 상대에 대한 신고는 24시간에 1건으로 제한되며, 추가 내용은 기존 신고에 덧붙여집니다.
7. 허위·반복 신고(5건 이상 전부 기각)는 신고자에게 경고가 발송됩니다.

## 6. 이의신청
1. 제재를 받으면 정지 화면 또는 설정에서 **[이의신청]**을 할 수 있습니다. 제재 통보 후 **7일 이내, 제재 1건당 1회**.
2. 사유(1,000자 이내)와 첨부 1장을 제출하면 관리자가 **72시간 이내**에 판정합니다. 이의신청 중에도 제재는 유지됩니다.
3. 인용 시 제재가 삭제되고 하향된 인증 단계가 복구됩니다. 기각 시 사유 한 줄과 함께 통보되며 같은 제재에 재신청할 수 없습니다.
4. 사기·미성년·불법촬영물 사유의 영구 이용정지는 이의신청 시에도 증거 기록이 삭제되지 않습니다.
