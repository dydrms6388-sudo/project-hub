공유된 시간표를 보고 있어요. 내 브라우저에 저장하거나, 나만의 시간표를 새로 만들 수 있습니다.

이미지 저장 · 공유

이미지 저장이 안 되면(일부 인앱 브라우저) 새 탭에 이미지가 열립니다. 길게 눌러 저장하세요. 공유 링크에는 시간표 내용이 주소에 담겨 있어 서버 없이 그대로 복원됩니다.

시간표 만들기, 이렇게 쓰세요

개강하면 가장 먼저 하는 일이 시간표 정리입니다. 이 도구는 로그인이나 앱 설치 없이 브라우저에서 바로 시간표를 만들 수 있는 무료 시간표 제작기입니다. 대학생은 30분 단위 시간 모드로, 중·고등학생은 교시 모드로 전환해 쓸 수 있고, 과목을 추가하면 색이 자동으로 배정되어 보기 좋은 시간표가 완성됩니다.

완성한 시간표는 이미지(PNG)로 저장해 배경화면·프로필·커뮤니티에 올릴 수 있습니다. 특히 아이폰 배경화면 비율(9:19.5) 프리셋을 고르면 잠금화면에 딱 맞는 세로 이미지가 만들어집니다. 입력한 내용은 이 브라우저의 localStorage에만 저장되며 서버로 전송되지 않습니다.

사용법

  1. 상단에서 대학 / 중·고등 모드를 선택하고, 표시 요일·시간 범위(또는 교시 수)를 조절합니다.
  2. 과목명·장소·요일·시간을 입력하고 시간표에 추가를 누릅니다. 같은 과목명은 같은 색으로 묶입니다.
  3. 표에서 과목 블록을 누르면 수정·삭제할 수 있습니다.
  4. PNG로 저장으로 이미지를 내려받거나, 공유 링크 복사로 친구에게 시간표를 보낼 수 있습니다. 링크를 받은 사람은 똑같은 시간표를 바로 볼 수 있어요.

자주 묻는 질문

시간표가 저장되나요? 다시 들어와도 남아 있나요?
네. 입력하는 즉시 사용 중인 브라우저의 localStorage에 자동 저장되어, 같은 브라우저로 다시 방문하면 그대로 복원됩니다. 다만 브라우저 데이터(사이트 데이터)를 삭제하면 함께 지워지니, 완성본은 이미지 저장이나 공유 링크로 백업해 두는 것을 추천합니다.
아이폰(사파리)에서 이미지 저장이 되나요?
네. 저장 버튼을 누르면 PNG 파일이 다운로드됩니다. 일부 인앱 브라우저(카카오톡 등)에서는 다운로드가 제한될 수 있는데, 이 경우 새 탭에 이미지가 열리므로 이미지를 길게 눌러 "사진에 저장"을 선택하면 됩니다.
공유 링크는 어떻게 작동하나요? 서버에 저장되나요?
서버에 저장되지 않습니다. 시간표 내용 전체가 링크 주소의 ?r= 뒤에 인코딩되어 담기고, 링크를 연 브라우저에서 다시 풀어 그대로 그려줍니다. 링크만 있으면 언제든 같은 시간표를 볼 수 있고, 받은 사람이 "내 시간표로 저장"을 눌러 이어서 편집할 수도 있습니다.
공강·야간 수업도 넣을 수 있나요?
대학 모드에서 표시 시간 범위를 8시~24시까지 조절할 수 있어 야간 강의도 넣을 수 있습니다. 토요일·일요일 수업이 있다면 표시 요일을 "월~토" 또는 "월~일"로 바꾸세요.
과목 색을 직접 고를 수 있나요?
색은 과목명 기준으로 자동 배정됩니다(같은 과목 = 같은 색). 16색 팔레트를 순서대로 사용해 과목끼리 겹치지 않게 배정되므로 별도 설정 없이도 깔끔하게 구분됩니다.
