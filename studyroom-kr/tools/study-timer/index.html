공부 시간 측정 도구 소개

"오늘 얼마나 공부했지?"를 감이 아니라 숫자로 확인하는 과목별 스톱워치입니다. 과목을 등록해 두고 공부를 시작할 때 ▶ 버튼을 누르면 시간이 흘러가고, 멈추면 그 시간이 오늘 날짜·해당 과목으로 자동 기록됩니다. 한 번에 하나의 과목만 측정되므로 과목을 바꾸면 이전 측정은 자동으로 저장됩니다.

기록은 최근 7일 그래프로 요약되어 과목별 비중과 요일별 흐름을 한눈에 볼 수 있고, 전체 기록은 CSV 파일로 내보내 엑셀·스프레드시트에서 정리할 수도 있습니다. 측정 중 새로고침해도 시작 시각이 저장되어 있어 시간이 끊기지 않습니다. 모든 데이터는 브라우저에만 저장됩니다.

사용법

  1. 과목 추가 칸에 과목명을 입력하고 추가합니다.
  2. 공부를 시작할 때 과목 옆의 ▶ 시작을 누릅니다. 다른 과목을 누르면 자동으로 전환됩니다.
  3. 쉬거나 끝낼 때 ■ 정지를 누르면 기록이 저장됩니다.
  4. 주간 통계에서 그래프를 확인하고, 필요하면 CSV로 내보내세요.

자주 묻는 질문

측정 중에 실수로 탭을 닫으면 어떻게 되나요?
측정 시작 시각이 브라우저에 저장되어 있어, 다시 페이지를 열면 측정이 이어진 상태로 복원됩니다. 닫혀 있던 시간도 포함해서 계산됩니다.
1분 미만도 기록되나요?
초 단위까지 기록됩니다. 다만 10초 미만의 아주 짧은 측정은 실수로 판단해 저장하지 않습니다.
CSV 파일은 어떤 형식인가요?
날짜, 과목, 공부 시간(분) 세 열로 내보냅니다. UTF-8 BOM이 포함되어 엑셀에서 열어도 한글이 깨지지 않습니다.
여러 기기에서 같이 쓸 수 있나요?
서버 없이 브라우저 저장소만 사용하므로 기기 간 동기화는 되지 않습니다. 주로 쓰는 기기 한 곳에서 기록하는 것을 추천합니다.
