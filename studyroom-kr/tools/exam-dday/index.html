시험 디데이 계산기 소개

중간고사·기말고사·수능·자격증·편입 시험까지, 다가오는 시험을 등록하면 남은 날짜를 D-day 형식으로 계산해 주는 도구입니다. 여러 시험을 동시에 등록할 수 있고, 날짜가 가까운 순서로 자동 정렬되며 지난 시험은 D+ 형식으로 표시됩니다. 등록한 목록은 브라우저에 자동 저장되어 매일 들어와서 확인하는 위젯처럼 쓸 수 있습니다.

공부 자극이 필요하다면 배경화면 이미지 만들기를 활용해 보세요. 아이폰 배경화면 비율(9:19.5)로 D-day가 크게 박힌 이미지를 만들어 잠금화면에 걸어두면 폰을 열 때마다 남은 날짜가 보입니다. 디데이 계산은 자정(0시) 기준이며, 시험 당일은 D-day로 표시됩니다.

사용법

  1. 시험 이름과 날짜를 입력하고 디데이 추가를 누릅니다. 여러 개 등록 가능합니다.
  2. 카드에서 남은 날짜를 확인합니다. 카드 우측 상단 ✕로 삭제할 수 있습니다.
  3. 배경화면 만들기에서 메인 시험·비율·테마를 고르고 PNG로 저장하세요.
  4. 공유 링크를 복사하면 친구도 같은 디데이 목록을 볼 수 있습니다(스터디 그룹용).

자주 묻는 질문

D-day 계산 기준이 어떻게 되나요?
날짜(자정) 기준입니다. 오늘이 시험일이면 D-day, 내일이면 D-1로 표시됩니다. 시간 단위가 아닌 날짜 단위로 계산하므로 오후에 확인해도 값이 달라지지 않습니다.
등록한 시험이 사라지지 않나요?
브라우저 localStorage에 자동 저장되어 재방문 시 그대로 남아 있습니다. 다만 브라우저 데이터 삭제 시 함께 지워지니, 중요한 목록은 공유 링크를 만들어 메모해 두면 백업이 됩니다.
배경화면 이미지가 아이폰 화면에 딱 맞나요?
9:19.5 비율(1170×2532px)로 생성되어 최근 아이폰 잠금화면에 맞습니다. 위쪽에는 시계가 가리지 않도록 여백을 두고 D-day를 중앙에 배치했습니다. 안드로이드에서도 세로 배경화면으로 사용할 수 있습니다.
알림(푸시)도 오나요?
이 도구는 서버 없이 동작하는 웹페이지라 푸시 알림은 제공하지 않습니다. 대신 배경화면 이미지를 걸어두거나, 홈 화면에 이 페이지를 추가해 두면 빠르게 확인할 수 있습니다.
