스터디룸은 어떤 사이트인가요?

스터디룸은 중·고등학생과 대학생이 학기 중 자주 검색하는 계산과 정리 작업을 한곳에 모은 웹 도구 모음입니다. 시간표를 만들고, 학점을 계산하고, 시험까지 남은 날을 세고, 집중 시간을 기록하는 일 모두 앱 설치나 회원가입 없이 브라우저에서 바로 할 수 있습니다.

모든 도구는 서버 없이 브라우저에서만 동작합니다. 입력한 시간표·성적·공부 기록은 사용 중인 기기의 저장 공간(localStorage)에만 저장되고 외부로 전송되지 않습니다. 그래서 로그인이 필요 없고, 대신 브라우저 데이터를 삭제하면 기록도 함께 지워집니다. 중요한 내용은 이미지 저장이나 공유 링크로 백업해 두세요. 이름·전화번호·주민등록번호 같은 민감한 개인정보는 어떤 도구에서도 수집하지 않습니다.

이렇게 쓰면 좋아요

  • 개강 첫 주 — 시간표 만들기로 강의 시간표를 정리하고 이미지로 저장해 배경화면으로 사용
  • 학기 중 — 공부 계획표로 주간 계획을 세우고, 뽀모도로·공부 시간 측정으로 실제 공부량 확인
  • 시험 기간 — 시험 디데이로 일정을 관리하고 암기 카드로 반복 복습
  • 과제 마감 — 글자수 세기로 분량을 맞추고 참고문헌 생성기로 서식 정리
  • 성적 발표 후 — 학점 계산기로 누적 평점을 확인하고 다음 학기 목표 학점 역산

자주 묻는 질문

회원가입이나 로그인이 필요한가요?
필요하지 않습니다. 모든 도구가 브라우저에서 바로 실행되며 계정 없이 사용할 수 있습니다.
입력한 정보는 어디에 저장되나요?
사용 중인 브라우저의 localStorage에만 저장됩니다. 서버로 전송되거나 다른 사람이 볼 수 있는 곳에 올라가지 않습니다. 다른 기기와 동기화되지 않는 것도 같은 이유입니다.
모바일에서도 쓸 수 있나요?
모든 도구가 모바일 화면에 맞춰 만들어져 있습니다. 시간표나 계획표처럼 표가 넓은 도구는 좌우로 스크롤해서 확인할 수 있고, 이미지 저장·공유 기능도 모바일에서 동작합니다.
계산 결과를 그대로 믿어도 되나요?
학점·내신 등급·출석 기준처럼 학교 규정이 얽힌 계산은 학교마다 세부 규칙이 달라 참고용 값입니다. 정확한 수치는 학교 성적표와 학칙, 강의계획서로 확인해 주세요.
