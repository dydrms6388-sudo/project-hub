# 추가 기능 브레인스토밍 10선 — "토스증권을 이기는 법"

작성일: 2026-09-02 · 상태: 브레인스토밍(PRD 미반영) · 법적 전제: A안(추천 없는 데이터 도구) 유지

## 0. 전제 — 토스와 같은 링에서 싸우지 않는다

| 토스증권의 강점 (우리가 못 이기는 것) | 토스증권의 구조적 빈칸 (우리가 이기는 것) |
|---|---|
| 실시간 시세·매매 체결·소수점 거래 (증권사 라이선스) | **조건 스크리너 / 백테스트 없음** — "왜 이 종목인가"를 검증할 도구가 없다 |
| 커뮤니티 규모, 주주 인증 토론 | **세금 설계 없음** — 양도세·금융소득종합과세·ISA 비교는 증권사가 건드리기 애매한 영역 |
| 앱 UX, 브랜드, 마케팅 예산 | **포트폴리오 리스크 분석 없음** — 섹터 편중·ETF 중복·상관관계 |
| 뉴스·요약 콘텐츠 | **자기 상품 편향** — 증권사는 "거래를 늘리는" 인센티브, 우리는 "검증"이 상품 |
| "주식 모으기" 자동 적립 마케팅 | **적립을 검증해 주는 도구 없음** — "N년 전부터 샀다면"을 실데이터로 보여주지 않는다 |

> 포지셔닝 한 줄: **토스는 사는 곳, 스톡랩은 사기 전에 확인하는 곳.** 토스 사용자가 매매 직전에 우리 탭을 하나 더 여는 습관을 만들면 이긴다.

평가 기준: 임팩트(리텐션·바이럴·SEO) / 솔로 개발 난이도 / 법적 리스크(A안 유지 가능성) / 데이터 의존(P1 데이터로 가능한지).

## 1. 리딩방 팩트체크 — "이 종목, 데이터로 보면?"
- **무엇**: 종목명 하나 입력 → 카드 1장: 밸류에이션 위치(PER/PBR 5년 백분위), 최근 20/60일 수익률과 거래대금 배수, 최근 30일 주요 공시(유상증자·전환사채·최대주주 변경 등 팩트 플래그), 소액주주 비율, 신용잔고 추이. 판단 문장 없음, 숫자와 "주의 플래그"만.
- **토스 대비**: 토스는 종목 페이지에 시세·뉴스·커뮤니티가 있지만 "리딩방에서 들은 종목을 30초 안에 검증"하는 프레임이 없다. 우리 타깃(리딩방에 지친 층)의 존재 이유 그 자체.
- **법적**: 사실 데이터 나열 + "참고 자료" 고지. "위험/추천" 단어 금지, 플래그 명칭은 "확인 항목"으로. 특정 리딩방 실명 언급 금지(명예훼손).
- **데이터**: P1(재무·일봉) + 공시 목록(DART list API) → P2 초 가능. 임팩트 ★★★★★ / 난이도 ★★ / 법적 ★★(관리 가능).
- **바이럴**: 카드 PNG에 "tomatoeggcat.com/stocklab/check/{code}" 워터마크. 커뮤니티에서 "팩트체크 짤"로 돌게.

## 2. 스크리너 → 백테스트 원클릭 — "이 조건, 과거 10년이었다면?"
- **무엇**: 스크리너 결과 화면에 버튼 하나. 현재 필터 조건을 그대로 과거로 돌려 연 1회/분기 리밸런싱 가상 포트폴리오의 CAGR·MDD·승률·KOSPI 대비 초과수익을 즉시 표시. 결과 URL 공유 + 카드.
- **토스 대비**: 존재하지 않는 기능. 젠포트·퀀터스가 있지만 "스크리너에서 끊김 없이" 이어지는 UX는 없다.
- **법적**: "과거 성과는 미래 수익을 보장하지 않음" 필수, 생존편향·룩어헤드 방지 원칙 공개(docs/11 §백테스트).
- **데이터**: `financial_statements`(분기 히스토리) + 20년 일봉 필요 → P2 핵심. 임팩트 ★★★★★ / 난이도 ★★★★ / 법적 ★★.

## 3. 배당 현금흐름 설계 — "월 100만원 배당 받으려면?"
- **무엇**: (a) 배당 캘린더: 배당락·지급월을 종목/ETF별로 12개월 그리드에 히트맵. (b) 내 포트폴리오 입력 → 월별 예상 배당 현금흐름. (c) 역산: 목표 월 배당액 → 현재 배당수익률 기준 필요 투자금 + 월배당/분기배당 조합 시뮬레이션.
- **토스 대비**: 토스는 종목별 배당 정보만 있고 "설계"가 없다. 고배당 스크리너(P1)와 자연 연결.
- **법적**: "예상 배당은 직전 배당 기준 가정치이며 기업이 변경할 수 있음" 고지. 종목 조합 "제안" 대신 "사용자가 고른 조합의 계산 결과".
- **데이터**: P1 dividends + 지급월 필드 추가(DART 배당 공시). 임팩트 ★★★★ / 난이도 ★★ / 법적 ★. **P1.5로 당겨도 됨.**

## 4. 포트폴리오 X-ray — ETF 뚫어 보기
- **무엇**: 보유 종목·ETF·수량 입력 → 섹터/시장/팩터(가치·성장·배당) 비중, **ETF 구성종목 look-through** 로 "숨은 중복"(예: TIGER 200 + 삼성전자 직접 보유 → 실제 삼성전자 비중 27%), 상관계수 히트맵, 집중도(HHI), 리밸런싱 계산(목표 비중 → 매매 수량이 아닌 **"조정 필요 금액"** 표시).
- **토스 대비**: 토스는 수익률과 종목 리스트만. 리스크 구조를 보여주는 국내 무료 도구는 거의 없다.
- **법적**: 리밸런싱 "제안" 표현 금지 → "목표 비중과의 차이". 매수/매도 수량 표시 대신 금액 차이.
- **데이터**: ETF 구성종목(KRX ETF PDF 파일 일배치) 추가 필요. 임팩트 ★★★★ / 난이도 ★★★ / 법적 ★★.

## 5. 세금 최적화 시뮬레이터 세트 (SEO 킬러)
- **무엇**: ① 해외주식 양도세 — 연말 손익 통산 시뮬레이터(250만원 기본공제 활용, "손실 종목 실현 시 절세액"), ② 금융소득종합과세 2,000만원 경계 계산기(배당+이자 합산, 초과 시 예상 추가 세액), ③ ISA vs 일반계좌 vs 연금저축 절세 비교(3년/5년/10년), ④ 국내주식 대주주 요건 체크(종목별 보유액 기준).
- **토스 대비**: 증권사는 세무 상담 오해 소지 때문에 계산기를 잘 안 만든다. tomatoeggcat 계산기 SEO 노하우(연봉·DSR·양도세) 직이식.
- **법적**: 세법은 매년 바뀜 → 기준연도 명시, "세무 상담 아님" 고지. 금융투자소득세 시행 여부 등은 **확인 필요** 항목으로 연 1회 갱신 루틴.
- **데이터**: 사용자 입력만(외부 데이터 불필요). 임팩트 ★★★★(SEO) / 난이도 ★★ / 법적 ★. **P1에 바로 추가 가능.**

## 6. DCA 타임머신 — "5년 전부터 매달 30만원씩 이 ETF를 샀다면"
- **무엇**: 종목/ETF + 월 적립액 + 시작 시점 → 실제 과거 일봉으로 적립식 결과(총 투자금·평가금·수익률·최대 낙폭 구간·"가장 아팠던 달"), 거치식 vs 적립식 비교, 결과 카드 PNG. 복리 계산기의 "가정"을 "실측"으로 바꾼 버전.
- **토스 대비**: 토스 "주식 모으기"는 실행 도구, 우리는 검증 도구. 토스 사용자가 모으기 전에 우리에게 온다.
- **법적**: "과거 실측이며 미래 보장 아님", 배당 재투자 가정 명시. 특정 종목 결과가 좋아도 추천 문구 금지.
- **데이터**: daily_prices 5~20년(P1 파이프라인 `--full` 백필). 임팩트 ★★★★★(바이럴) / 난이도 ★★ / 법적 ★★. **P1.5 최우선 후보.**

## 7. 전략 마켓 + 팔로우 (UGC, 프로)
- **무엇**: 유저가 만든 스크리너 조건식을 공개 → 동일 기간 실측 성적으로 자동 랭킹 → 팔로우하면 "조건 충족 종목 목록이 바뀔 때" 알림. 작성자에게 팔로워 수·배지. 월간 시즌 리셋으로 콘텐츠 순환(판결소/티어랩 노하우).
- **토스 대비**: 토스 커뮤니티는 "의견", 우리는 "검증된 규칙". 토스가 구조적으로 못 하는 UGC.
- **법적 (가장 주의)**: 유저가 조건식 설명에 리딩성 문구를 쓰면 플랫폼 리스크 → 설명란에도 금지 표현 필터 적용, "조건식" 이외 종목 직접 언급 금지, 유료 팔로우(수익 배분)는 유사투자자문 소지가 있어 **P3 이후 법률 검토 전 금지**.
- **데이터**: P2 백테스트 엔진 위에. 임팩트 ★★★★ / 난이도 ★★★★ / 법적 ★★★★.

## 8. 시장 온도계 — 밸류에이션 밴드 대시보드
- **무엇**: KOSPI/KOSDAQ 전체 PBR·PER 10년 백분위 밴드, 52주 신고가/신저가 종목 비율, 거래대금 회전율, 신용잔고 비율, 외국인 순매수 누적 — 감정 단어 없이 "지금 시장이 역사적으로 어디 있나" 팩트 계기판. 매일 06:00 스냅샷 카드 자동 생성(오늘의 주식과 같은 크론).
- **토스 대비**: 토스는 "실시간 인기 종목"(FOMO 유발). 우리는 "밸류에이션 맥락"(냉각). 브랜드 대비 극대화.
- **법적**: "공포/탐욕", "바닥/고점" 단어 금지 → 백분위 숫자만. 임팩트 ★★★(재방문 훅·SEO) / 난이도 ★★ / 법적 ★.
- **데이터**: pykrx 시장 지표 일배치 추가. **P1.5 가능.**

## 9. 목표 역산 플래너 + 달성 확률
- **무엇**: "10년 안에 1억" → 월 적립·기간·초기자금 조합별 **필요 수익률** 산출 → 자산군(KOSPI·S&P500·국채·예금) 과거 30년 수익 분포로 몬테카를로 → "이 계획의 과거 기준 달성 비율 N%". 계획을 URL로 저장·공유, 매월 진행률 체크인(알림).
- **토스 대비**: 토스 "목표 저축"은 저축 상품 유도. 우리는 자산군 중립 확률 계산.
- **법적**: "확률은 과거 분포 기반 시뮬레이션이며 예측 아님" + 재미용 고지. 특정 상품 제시 금지.
- **데이터**: 지수 월간 수익률(무료 공개 데이터). 임팩트 ★★★ / 난이도 ★★★ / 법적 ★★. 복리 계산기와 내부링크로 SEO 클러스터.

## 10. 조건 빌더 알림 엔진 — "주식판 IFTTT"
- **무엇**: 가격·지표·공시·배당·랭킹 이벤트를 AND/OR로 조합하는 규칙 빌더. 예: "보유 종목에 유상증자 공시 AND 당일 -5% 이하" / "저PBR 프리셋에 새 종목 진입" / "배당락 D-3 AND 배당수익률 5% 이상". 채널: 이메일(베이직) → 알림톡·푸시(프로). 쿨다운·일일 한도로 스팸 방지.
- **토스 대비**: 토스 알림은 가격·뉴스 단일 조건. 복합 조건 + 공시 트리거는 없다.
- **법적**: 알림 문구는 "조건 충족" 사실 통지만(정보통신망법상 거래관계 정보, docs/11 §알림). "지금 확인하세요" 류 CTA 금지.
- **데이터**: P2 시그널 파이프라인 위에 규칙 평가기. 임팩트 ★★★★(유료 전환 핵심) / 난이도 ★★★★ / 법적 ★★.
