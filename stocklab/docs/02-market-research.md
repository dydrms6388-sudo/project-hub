# 02. 시장조사 — 경쟁 서비스 비교와 스톡랩 포지셔닝

> 작성: Wave 0 검증팀 (시장조사) · 2026-09-02 · 상태: **데스크 리서치(기억 기반), 가격·법적 지위는 전부 확인 필요**
> 이 샌드박스는 외부 웹(경쟁사 사이트 포함) 접속이 제한되어 가격·기능은 작성자의 기존 지식에 기반한다. **가격은 ±변동 가능, 유사투자자문업 신고 여부는 금감원 '유사투자자문업자 신고현황' 공시에서 상호로 검색해 확인할 것.**

## 3. 가격 지형

| 구간 | 월 요금 | 해당 서비스(확인 필요) | 시사점 |
|---|---|---|---|
| 무료 | 0 | 네이버, HTS/MTS, 인베스팅 무료, 알파스퀘어 무료, 버틀러 무료 | 지불 의사 낮은 다수 → **광고 + 전환 퍼널** |
| 저가 | ≈ 5,000~15,000 | 버틀러 프리미엄, 알파스퀘어 프리미엄, 인베스팅 Pro, 퀀터스 하위 | **스톡랩 베이직 ₩9,900 이 속하는 구간.** "커피 두 잔" 심리가 통하는 상한선은 ₩9,900 |
| 중가 | ≈ 20,000~40,000 | 퀀트킹, 젠포트 프리미엄, 퀀터스 상위, 아이투자 멤버십 | **스톡랩 프로 ₩29,000** — 이 구간은 "백테스트+알림" 이 있어야 정당화됨(P2 이후 판매 개시 권고) |
| 고가 | 5만원 이상 | 리딩방·유사투자자문 유료 회원(월 수십만원) | 스톡랩 미진입 영역 |

**시사점:** 프로 ₩29,000 은 P1 기능(스크리너 2종 + 계산기)만으로는 근거가 약하다. **P1 은 베이직만 판매(또는 유료 미개방)**, 프로는 백테스트·알림톡 출시와 함께 개방을 권고한다(`03-unit-economics.md` 시나리오도 이 가정).

## 4. 포지셔닝

**포지셔닝 문장:**
> 스톡랩은 **가입 없이 바로 쓰는 한국 주식 데이터 도구**다. 종목을 추천하지 않고, 사용자가 정한 조건으로 전 상장사를 걸러 주고(스크리너), 숫자를 계산해 주고(계산기), 과거 데이터로 규칙을 검증하게 해 주며(백테스트), 조건이 충족되면 알려 준다(알림). 리딩방의 반대편, 증권사 앱보다 가볍고, 퀀트 프로그램보다 쉽다.

**타깃:** 20~40대 개인 투자자 중 (1) 재무 지표 기반으로 종목을 걸러 보고 싶지만 HTS 조건검색이 어렵다고 느끼는 사람 (2) 배당·복리 계산을 검색으로 찾아오는 사람(허브 유입) (3) 리딩방에 불신이 있는 사람.

### 4.1 차별화 표

| 축 | 경쟁 일반 | 스톡랩 | 근거 |
|---|---|---|---|
| 진입 | 계좌·로그인·설치 | **비로그인 즉시 실행** | 온보딩 마찰 0 → SEO 트래픽의 체험 전환율 극대화 |
| 신뢰 | 추천·리딩·수익률 광고 | **추천 없음 선언 + 규칙 완전 공개** | A안. "왜 이 종목이 나왔는지" 조건을 항상 노출 |
| 데이터 투명성 | 실시간 강조 | **전일 종가·공시 기준일 명시** | 지연 데이터를 약점이 아니라 "정직함" 으로 포지셔닝 |
| 가격 | 2~4만원 | **₩9,900 베이직** | 저가 구간 진입, 프로는 기능 확장 후 |
| 모바일 | PC 우선 또는 앱 설치 | **모바일 웹 우선, 앱 설치 불필요** | 링크 공유 → 바로 열림 |
| 확장 | 자동매매·콘텐츠 | **계산기 ↔ 스크리너 ↔ 알림 크로스** | 허브(tomatoeggcat) 트래픽 재활용 |
| 복잡도 | 팩터 수십 개 | **2~5개 조건, 프리셋 + 조정** | "쉬운 퀀트" |

## 5. 리스크 3가지

| # | 리스크 | 확률/영향 | 대응 |
|---|---|---|---|
| R1 | **무료 대체재가 강력하다** — HTS 조건검색·네이버가 무료이고, 지불 의사가 있는 사용자는 이미 퀀트킹/퀀터스 사용 중. 5% 전환 가정이 과대일 수 있음 | 중/높음 | 유료 개방 전 **대기열·사전 예약으로 지불 의사 측정**. 전환율 2% 시나리오도 `03` 에서 계산(보수 시나리오). AdSense 가 최소 고정비를 커버하도록 무료 트래픽 우선 |
| R2 | **데이터 공급 취약성** — pykrx 중단·KRX 재배포 문제(01 문서 §6). 유료 구독자에게 데이터 정지는 즉시 환불 사유 | 중/높음 | 폴백 체인, 데이터 기준일 노출, 공공데이터 API 검토, 약관에 "데이터 지연·중단 가능" 명시 |
| R3 | **법적 경계 오인** — `/today` 1종목 노출, 알림 문구가 "추천"으로 해석되면 유사투자자문업 미신고 민원·신고 대상 | 중/매우 높음 | 00 문서 §5.3 완화안 즉시 적용, 표현 가드 CI, 법률 자문 1회(비용 확보) |

추가 관찰(리스크 아님, 기회): 2024~2026 유사투자자문업 규제 강화로 리딩방 신뢰가 하락 → "추천 없는 도구" 메시지가 시장 정서와 부합.
