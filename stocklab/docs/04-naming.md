# 04. 네이밍 — 3안 비교와 작업명 확정

> 작성: Wave 0 검증팀 (네이밍) · 2026-09-02 · 상태: **작업명 확정, 상표·도메인 조회는 확인 필요**
> 이 샌드박스는 KIPRIS·WHOIS·앱스토어에 접속할 수 없어 충돌 조회를 수행하지 못했다. 아래 충돌 위험은 작성자의 일반 지식에 근거한 **추정**이다.

| 요건 | 이유 |

| 상표 등록 가능성(식별력) | 지정상품 9류(소프트웨어)·36류(금융정보)·42류(SaaS) |

## 2. 3안 비교

| 항목 | 1안 **스톡랩 / StockLab** (현 작업명) | 2안 **스크리너랩 / ScreenerLab** | 3안 **퀀트캣 / QuantCat** |
|---|---|---|---|
| 의미 | 주식(Stock) + 실험실(Lab) — "데이터로 실험하는 곳" | 핵심 기능(스크리너)을 그대로 이름에 | 퀀트(정량) + 고양이(허브 브랜드 TomatoEggCat 의 Cat 계승) |
| 법적 뉘앙스 | 중립. 추천 연상 없음 | 중립. 기능 서술형 | "퀀트"가 전략·추천 뉘앙스를 약간 가짐(퀀트 리딩방 사례) — 낮은 위험 |
| 발음/기억 | ◎ 짧고 직관적 | ○ 길고(5음절) 발음 다소 어색 | ◎ 귀에 남음, 캐릭터화 용이 |
| SEO | "스톡랩" 단일 키워드 검색 시 동명 서비스와 경쟁 가능 | "스크리너" 는 일반명사 → 브랜드 검색 불리, 기능 검색엔 유리 | 고유성 높아 브랜드 검색 유리 |
| **도메인 충돌(추정)** | `stocklab.com`/`.co.kr`/`.kr` **선점 가능성 매우 높음** → 서브도메인 운영으로 우회. `stocklab.kr` 가용성 **확인 필요** | `screenerlab.com` 가용 가능성 중간 **확인 필요** | `quantcat.com` 선점 가능성 중간, `.kr` 가용 가능성 높음 **확인 필요** |
| **브랜드 충돌(추정)** | 영문 "StockLab/Stocklab" 은 해외에 동명 앱·핀테크·연구소 존재 가능성 **높음**. 국내 "스톡랩" 사용 업체 존재 여부 **확인 필요** | 낮음(기술 서술어 조합) | 낮음~중간. 해외 "QuantCat" 소규모 프로젝트 존재 가능 **확인 필요** |
| **상표 등록 가능성** | **낮음~중간**: Stock + Lab 은 식별력 약한 결합(36류·42류에서 기술적 표장으로 거절 가능). 선등록 "STOCKLAB" 유사 표장 존재 시 충돌 → **KIPRIS 확인 필요** | 낮음: "Screener" 는 기능 일반명 → 식별력 부족 거절 가능성 | **중간~높음**: 조어 결합, 식별력 있음 → **KIPRIS 확인 필요** |
| 확장성 | 백테스트·알림·모의투자 모두 포괄 | 스크리너 외 기능(계산기·알림) 포괄 어려움 | 포괄. 캐릭터·굿즈·SNS 활용 여지 |
| 허브 일관성 | 중립 | 중립 | ◎ TomatoEggCat 과 세계관 공유 |
| 리스크 요약 | 상표 약함·동명 다수, 그러나 **서브도메인+비독점 사용이면 실무 위험 낮음** | 기능 종속·긴 이름 | "퀀트" 연상, 진지함 부족 우려 |

## 3. 결정

| 항목 | 결정 |
|---|---|
| **작업명(코드·URL·문서)** | **스톡랩 / StockLab 유지** — `stocklab.tomatoeggcat.com`, 코드베이스 `stocklab/`, `SITE.name = "스톡랩"` 그대로 |
| 근거 | 이미 코드·도메인·문서에 반영됨. 서브도메인 운영으로 독립 도메인 불필요. 상표 식별력이 약하다는 것은 "우리도 등록 어려움" 이자 "타인도 독점 어려움" 이라 실무 충돌 위험이 낮음 |
| **변경 조건(둘 중 하나면 3안 퀀트캣으로 전환 검토)** | (1) KIPRIS 조회에서 9/36/42류에 **"스톡랩" 또는 "STOCKLAB" 이 금융정보·소프트웨어 지정상품으로 선등록**되어 있음 (2) 국내에서 동명 금융 서비스가 **활발히 운영 중**(검색 1페이지 점유) |
| 대체 1순위 | 3안 퀀트캣/QuantCat (허브 세계관 일관성, 상표 가능성) |
| 상표 출원 | P1 에서는 **미출원**(비용 대비 효과 낮음). 유료 구독자 100명 도달 시 출원 검토(1류당 출원 약 6~7만원 + 등록료 — 금액 확인 필요) |

| 태그라인 | 현 `SITE.tagline` 유지: "데이터로 찾고, 시뮬레이션으로 검증하고, 알림으로 놓치지 않는 개인 투자자용 도구" — 단, "놓치지 않는" 은 00 문서 §4 #41 의 감정 유도 표현("놓치면 후회")과 구분되는 기능 서술이므로 허용. 필요 시 "알림으로 확인하는" 으로 완화 가능 |
