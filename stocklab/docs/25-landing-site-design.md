### 1.3 카피 초안
**히어로**
- H1(한 줄 가치): **"종목을 고르는 건 당신, 조건을 확인하는 건 데이터."**
  - 대안 A: "추천 대신 조건. 국내주식 스크리닝·백테스트·알림 도구"
  - 대안 B: "PER 10 이하, ROE 10% 이상 — 지금 몇 개인지 3초면 압니다."
- 부제: "PER·PBR·ROE·배당 조건으로 종목을 좁히고, 복리 계산과 백테스트로 검증하고, 조건이 다시 충족되면 알림을 받으세요. 스톡랩은 특정 종목의 매매를 권유하지 않습니다."
- CTA: `[저평가 스크리너 열기]` `.btn-primary` · `[오늘의 조건 충족 종목 보기]` `.btn-ghost`
- 신뢰 줄(text-xs muted): "KRX·DART 공개 데이터 · 매일 06:00 갱신 · 가입 없이 하루 5회 무료"

**섹션 3 위젯**
- P1 (TodayWidget + 카운트): 좌 — 오늘의 조건 충족 종목 카드 축약(종목명·전략·조건 2줄·기준일). 우 — 라이브 카운트 3개(`tnum`): "PER 10 이하 · PBR 1 이하 · ROE 10% 이상 종목 **{n}개**", "배당수익률 3% 이상 · 5년 연속 배당 **{n}개**", "전체 분석 종목 **{n}개** (KOSPI/KOSDAQ)". 카운트는 서버 컴포넌트에서 뷰 COUNT, 5분 캐시.
- P2 (RankingWidget): "이번 시즌 전략 랭킹 Top 3 (직전 36개월 시뮬레이션)" — 전략명 · 총수익률 · MDD, 1위만 상세 링크(무료), 하단 고지 "과거 성과가 미래 수익을 보장하지 않습니다."

**작동 방식 3단계**
1. **조건을 정합니다** — 프리셋으로 시작해 슬라이더로 조정하세요.
2. **과거 데이터로 검증합니다** — 같은 조건이 지난 5~20년에 어떤 결과를 냈는지 봅니다. (베이직)
3. **조건 충족을 알림으로 받습니다** — 매일 스크리너를 열지 않아도 됩니다. (베이직)

**요금제 티저**
- 제목: "무료로 시작하고, 필요할 때만 올리세요"
- 3열 요약: 무료 "스크리너 하루 5회(로그인 20회) · 계산기 · 오늘의 주식" / 베이직 ₩9,900 "무제한 스크리너 · 조건 저장 · 이메일 알림 · 백테스트 월 10회" / 프로 ₩29,000 "멀티팩터 · 알림톡·실시간 · 백테스트 무제한 · 전략 랭킹 참가"
- P1에서는 "베이직·프로는 준비 중입니다. 출시 알림 받기" 폼(이메일, 마케팅 동의 체크 + "(광고)" 고지).

### 1.4 FAQ 8문항 (FAQPage JSON-LD)
| Q | A |
|---|---|
| 스톡랩은 종목을 추천하나요? | 아닙니다. 스톡랩은 사용자가 정한 조건을 공개 데이터에 적용해 조건 충족 종목을 보여주는 도구입니다. 특정 종목의 매매를 권유하지 않으며, 투자 판단과 책임은 이용자 본인에게 있습니다. |
| 데이터는 어디서 오나요? | 시세는 한국거래소(KRX) 공개 데이터의 전일 종가, 재무 지표는 금융감독원 DART 공시 기준입니다. 매일 06:00(KST) 갱신되며 화면에 데이터 기준일을 표시합니다. |
| 실시간 시세인가요? | 무료·베이직은 전일 종가 기준 지연 데이터입니다. 프로 요금제에서 장중 실시간 시세(한국투자증권 API)를 제공할 예정입니다. |
| 무료로 얼마나 쓸 수 있나요? | 스크리너는 가입 없이 하루 5회, 로그인 시 하루 20회 실행할 수 있습니다. 복리 계산기와 오늘의 조건 충족 종목은 제한 없이 이용할 수 있습니다. |
| "오늘의 주식"은 어떻게 정해지나요? | 매일 06:00 기본 전략(PBR 1배 이하, ROE 10% 이상, 부채비율 150% 이하, 시가총액 1,000억 이상)의 조건을 충족한 종목 중 ROE 순으로 1개를 표시합니다. 최근 20거래일 내 표시된 종목은 제외합니다. 규칙은 공개되어 있습니다. |
| 백테스트 결과를 믿을 수 있나요? | 백테스트는 과거 데이터에 조건을 기계적으로 적용한 시뮬레이션입니다. 공시일 기준 재무 데이터와 상장폐지 종목을 포함해 편향을 줄이고, 수수료·세금·슬리피지를 반영하지만, 과거 성과가 미래 수익을 보장하지 않습니다. |

## 2. `/about` 소개

### 2.1 메타
- title: `스톡랩 소개 — 추천 없는 데이터 도구를 만드는 이유`
- description: `왜 추천 대신 조건인지, 데이터는 어디서 어떻게 가져오는지, 무엇을 하지 않는지 투명하게 밝힙니다.`

### 2.2 섹션·카피
**미션**
> 개인 투자자에게 필요한 것은 "정답"이 아니라 **스스로 조건을 세우고 확인할 수 있는 도구**라고 믿습니다. 스톡랩은 추천을 하지 않습니다. 대신 누구나 같은 공개 데이터로 같은 결과를 재현할 수 있게 규칙을 공개하고, 그 규칙이 과거에 어떤 결과를 냈는지 보여줍니다.

**우리가 하지 않는 것**
- 특정 종목의 매매를 권유하거나 목표 가격을 제시하지 않습니다.
- 수익을 약속하지 않습니다. 과거 성과는 미래 수익을 보장하지 않습니다.
- 실명·전화번호·주민등록번호를 수집하지 않습니다(알림톡 선택 시 전화번호만 동의 후 암호화 보관).
- 유료 리딩방·커뮤니티를 운영하지 않습니다.

**데이터 출처 투명성 표**
| 데이터 | 출처 | 갱신 | 지연 | 비고 |
|---|---|---|---|---|
| 종목 목록·일봉 시세 | 한국거래소(KRX) 공개 데이터 (pykrx / FinanceDataReader 경유) | 매일 05:00 KST 적재 → 06:00 반영 | 전일 종가 | 수정주가 반영(P2) |
| 재무 지표 (PER/PBR/ROE/부채비율 등) | 금융감독원 전자공시 DART OpenAPI | 공시 접수 후 다음 배치 | 최신 사업·분기보고서 기준 | 계산식 공개(아래) |
| 배당 (DPS·수익률·연속배당·배당락일) | KRX + DART | 매일 | | |
| 지수 (KOSPI/KOSDAQ/KOSPI200) | KRX | 매일 | 전일 | 벤치마크 |
| 실시간 시세 (프로, P2) | 한국투자증권 KIS Developers | 장중 실시간 | 15초 캐시 | 개인 이용 범위 |

**지표 계산식 공개**: PER = 시가총액 / 지배주주순이익(TTM) · PBR = 시가총액 / 지배주주지분 · ROE = 순이익(TTM) / 평균자본 · 부채비율 = 총부채 / 자본 · 배당수익률 = 주당배당금 / 전일 종가 · 배당성향 = 배당총액 / 순이익.

**한계 고지**: 지연 시세, 공시 반영 시차(최대 수 주), 데이터 오류 가능성 → "오류 신고" 링크(`contact@tomatoeggcat.com`).

**운영**: TomatoEggCat(개인 운영) · 문의 이메일 · 광고(AdSense)와 구독으로 운영 · 개인정보처리방침/이용약관 링크.
