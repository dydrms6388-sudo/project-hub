> 본 문서는 법률 자문이 아닙니다. "확인 필요" 표기 항목은 출시 전 변호사(자본시장법 전문) 또는 금융감독원 유사투자자문업 담당 부서에 확인해야 합니다.

## 1. 결론 요약

| 항목 | 결론 |
|---|---|
| 출시 전략 | **A안 = "추천 없는 데이터 도구 플랫폼"** (유사투자자문업 신고 없이 출시) |
| 핵심 원칙 | 스톡랩은 **사용자가 정한 조건으로 데이터를 필터링·계산·시뮬레이션** 하는 도구다. 특정 종목의 매매 방향·시점·가격에 대한 **의견을 내지 않는다.** |
| 가장 위험한 기능 | `/today` "오늘의 주식"(일 1종목 자동 선정). 조건 충족 종목이라도 **1종목만 노출하면 추천으로 오해**될 여지가 큼 → §5.3 완화안 필수 적용, 법률 자문 **확인 필요** |
| 유료화 근거 | 요금은 **도구 기능(스크리너 실행 횟수·알림·백테스트·저장)** 의 대가이며, 종목 의견의 대가가 아니다. 결제 화면/약관에 명시 |
| 전환 조건 | 아래 §7 의 B안 전환 트리거(콘텐츠형 기능 도입, 편집자 코멘트, 유료 종목 콘텐츠) 중 하나라도 하고 싶으면 **먼저** 유사투자자문업 신고 |

## 2. 법적 포지션 3분류 비교

| 구분 | 투자자문업 | 유사투자자문업 | 데이터 도구(스톡랩 A안) |
|---|---|---|---|
| 정의 | 금융투자상품의 가치 또는 투자판단에 관한 **자문에 응하는 것을 영업**으로 하는 것 | **불특정 다수인**을 대상으로 발행·송신되고 수시로 구입·수신할 수 있는 **간행물·출판물·통신물·방송 등**으로 투자조언을 하는 영업 | 사용자가 설정한 조건에 따라 공개 데이터를 **필터링·계산·시각화** 하는 소프트웨어. 투자판단에 관한 조언 없음 |

### 2.1 "조언"과 "도구"를 갈라주는 실무 판단 기준 (자체 정리, 확인 필요)

| 판단 요소 | 조언(규제 대상)에 가까움 | 도구(비규제)에 가까움 |
|---|---|---|
| 조건 설정 주체 | 서비스가 정함, 사용자는 결과만 봄 | **사용자가 설정**하거나 최소한 명시적으로 선택·확인 |
| 결과 개수 | 1개 또는 소수 "픽" | 조건 충족 **전체 목록**(정렬은 사용자 선택) |
| 방향성 | 매수/매도/보유 등 행동 지시 | 지표 값과 조건 충족 여부만 |
| 가격 | 목표가·적정가·진입가 제시 | 현재가·과거가·계산식 결과(예: 배당수익률) |
| 시점 | "지금", "이번 주" 등 타이밍 언급 | 데이터 기준일만 표시 |
| 어조 | 확신·기대·감정("놓치지 마세요") | 중립·서술("조건을 충족합니다") |
| 대가 | 종목 정보 자체에 과금 | 기능(횟수·알림·저장·속도)에 과금 |

## 3. A안 vs B안 비교

| 항목 | A안: 데이터 도구 (신고 없음) | B안: 유사투자자문업 신고 후 콘텐츠 병행 |
|---|---|---|
| 출시 속도 | 즉시 | 교육 이수 + 신고 처리 기간(수 주) — **확인 필요** |
| 비용 | 0 | 교육비·법률자문·약관 정비, 5년 갱신 |
| 가능 기능 | 스크리너·계산기·백테스트·알림·모의투자·랭킹 | + 종목 코멘트, 유료 리포트, "이번 주 관심 종목" 같은 편집 콘텐츠, 문자 발송형 정보 |
| 불가 기능 | 편집자 의견·픽·목표가 | 1:1 상담·양방향 채팅 자문(투자자문업 등록 필요) |
| 표현 자유도 | 낮음(본 문서 §4 준수) | 중간(단, 이익보장·손실보전·과장 금지) |
| 표시 의무 | 자율 면책 | 신고번호·유사투자자문업자 표시·환불 규정 등 |
| 민원 리스크 | 낮음(도구 오작동·데이터 오류 중심) | 높음(수익 관련 분쟁, 환불 분쟁이 소비자원 다발 유형) |
| AdSense | 일반 금융 콘텐츠 | 금융 조언 콘텐츠로 분류될 수 있어 정책 검토 필요 |
| 평판 | "중립 도구" | "리딩방"과 같은 카테고리로 묶일 위험 |
| **결정** | **채택 (P1~P2)** | P3 이후, 트리거 발생 시 재검토 |

|---|---|

| 메타데이터 | `metadata.title/description`, JSON-LD `description`, `og:title` 도 같은 `.ts/.tsx` 안에 있으므로 자동 커버됨. 알림톡 템플릿 문안이 별도 파일(`pipeline/templates/*.txt` 등)로 존재하면 ROOTS 에 추가 |
| CI | `npm run check` 를 Vercel 빌드 전 단계(`vercel.json` `buildCommand` 또는 GitHub Actions)에 연결 |
