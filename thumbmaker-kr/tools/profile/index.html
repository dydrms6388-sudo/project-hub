프로필 사진 만들기

원형 가이드가 표시되는 정사각 캔버스입니다. 저장 시 원형으로 잘린 투명 PNG로 내보낼 수 있어요.

프로필 사진 만들기 — 이 도구 소개

카카오톡·인스타그램·유튜브 등 대부분의 서비스는 프로필 사진을 원형으로 잘라 보여줍니다. 이 도구의 캔버스에는 원형 가이드(점선)가 항상 표시되어, 얼굴이나 이니셜이 원 밖으로 잘리지 않게 배치할 수 있습니다.

사진 없이도 배경색 + 이니셜 텍스트만으로 깔끔한 프로필을 만들 수 있고, 내보내기에서 "원형으로 자르기"를 켜면 원형으로 잘린 투명 PNG가 저장됩니다. 원형 파일이 필요 없는 서비스(업로드 후 자동으로 잘라 주는 곳)라면 옵션을 끄고 정사각으로 저장하세요.

사용법

  1. 사진을 올리거나, 이니셜 템플릿의 글자·배경색을 내 것으로 바꿉니다.
  2. 점선 원 가이드 안에 핵심(얼굴/이니셜)이 들어오게 드래그로 조정합니다.
  3. 내보내기에서 원형으로 자르기를 켜고(투명 PNG) 저장합니다.
  4. 서비스가 정사각 업로드를 요구하면 옵션을 끄고 저장하세요.

자주 묻는 질문

원형 PNG는 어디에 쓰나요?

문서·영상·웹사이트처럼 원형 그대로 얹어야 하는 곳에 유용합니다. 카카오톡·인스타 등 업로드 시 자동으로 원형 크롭되는 서비스에는 정사각 원본을 올리는 것이 좋습니다.

프로필 사진 권장 크기는요?

서비스마다 다르지만 800×800이면 대부분 충분합니다. 유튜브 채널 프로필은 800×800을 권장합니다.

사진 배경만 바꿀 수 있나요?

배경 제거 기능은 없습니다. 배경이 투명한 PNG를 올리면 배경 패널의 단색/그라데이션이 뒤에 깔립니다.

얼굴이 가장자리에서 잘려요.

점선 원이 실제 표시 영역입니다. 사진을 선택해 크기를 줄이거나 위치를 옮겨 원 안에 얼굴이 들어오게 하세요.
