블로그 대표 이미지 만들기

네이버 블로그·티스토리에서 무난하게 쓰이는 16:9 / 정사각 / 3:2 프리셋을 제공합니다.

블로그 대표 이미지 만들기 — 이 도구 소개

블로그 글의 첫인상은 대표 이미지(썸네일)가 만듭니다. 검색 결과와 블로그 홈, 카카오톡·SNS 공유 미리보기까지 같은 이미지가 노출되기 때문에, 제목이 또렷하게 읽히는 대표 이미지를 하나 만들어 두면 글의 클릭률이 눈에 띄게 달라집니다.

이 도구는 티스토리·네이버 블로그에서 두루 무난한 1200×675(16:9)를 기본으로, 목록형 스킨에 어울리는 정사각(800×800)과 3:2(900×600) 프리셋을 제공합니다. 시리즈 글이라면 같은 템플릿에 번호와 제목만 바꿔 통일감 있는 썸네일 세트를 만들어 보세요.

사용법

  1. 크기 선택에서 블로그 스킨에 맞는 비율(16:9/정사각/3:2)을 고릅니다.
  2. 템플릿을 적용하고 글 제목·카테고리 문구로 바꿉니다.
  3. 블로그 대표 색을 배경 패널에서 지정해 브랜드 톤을 유지합니다.
  4. JPG(품질 85~90)로 저장하면 화질과 용량의 균형이 좋습니다.

자주 묻는 질문

블로그 대표 이미지 크기는 얼마가 좋나요?

정해진 하나의 정답은 없지만, 공유 미리보기(오픈그래프)와 호환되는 16:9 계열(1200×675)이 가장 무난합니다. 블로그 스킨이 정사각 썸네일을 쓰면 800×800을 선택하세요.

글자가 목록 썸네일에서 잘려 보여요.

스킨에 따라 썸네일이 중앙 기준으로 잘립니다. 중요한 문구는 캔버스 중앙에 배치하고 가장자리 여백을 넉넉히 두세요.

시리즈 글 썸네일을 통일하고 싶어요.

한 번 만든 디자인을 저장(JSON) 기능으로 파일로 보관한 뒤, 매번 열기로 불러와 제목만 바꾸면 됩니다.

저작권 걱정 없이 상업 블로그에 써도 되나요?

네. 내장 폰트는 모두 오픈 라이선스이고 결과물에 워터마크가 없습니다. 직접 올린 사진의 권리만 확인하세요.
