카톡 배경 만들기 — 이 도구 소개

카카오톡 프로필 배경은 폰 화면 전체에 세로로 표시되므로 9:16 비율(1080×1920)로 만드는 것이 가장 깔끔합니다. 이 도구는 파스텔 그라데이션·손글씨 문구·이모지를 조합해 계절 인사, 상태 메시지 느낌의 글귀, D-day 안내 같은 배경 이미지를 만드는 데 맞춰져 있습니다.

프로필 사진과 이름이 화면 중앙~하단에 겹쳐 표시되는 점을 감안해, 문구는 상단 1/3 지점에 배치하는 것이 좋습니다. 완성본을 저장한 뒤 카카오톡 프로필 편집에서 배경 사진으로 선택하면 됩니다.

사용법

  1. 템플릿을 고르고 배경 색·그라데이션을 취향대로 바꿉니다.
  2. 문구는 화면 상단 1/3 부근에 배치합니다(하단은 프로필 UI와 겹침).
  3. 이모지 스티커로 포인트를 더합니다.
  4. PNG로 저장 후 카카오톡 프로필 관리에서 배경 사진으로 설정합니다.

자주 묻는 질문

카톡 프로필 배경 크기는 몇인가요?

공식 고정 규격은 없지만 폰 화면과 같은 9:16(1080×1920)으로 만들면 기종 대부분에서 잘리지 않고 표시됩니다.

글자가 프로필 이름에 가려져요.

카카오톡은 화면 중앙~하단에 프로필 사진·이름·메뉴를 겹쳐 보여줍니다. 문구를 상단 쪽으로 옮기세요.

멀티프로필 배경으로도 쓸 수 있나요?

네, 같은 이미지 규격을 사용하므로 그대로 설정할 수 있습니다.

사진 위에 글귀만 얹고 싶어요.

🖼 이미지로 사진을 올리고 "캔버스 꽉 채우기"를 누른 뒤, T 텍스트로 문구를 얹으면 됩니다.
