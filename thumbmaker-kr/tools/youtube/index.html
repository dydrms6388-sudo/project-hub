유튜브 썸네일 만들기 — 이 도구 소개

유튜브 썸네일은 클릭률(CTR)을 좌우하는 가장 중요한 요소입니다. 같은 영상이라도 썸네일에 따라 노출 대비 클릭이 몇 배씩 차이 나는 일이 흔하죠. 이 도구는 유튜브 공식 권장 크기인 1280×720픽셀(16:9) 캔버스에서 시작해, 템플릿 선택 → 문구 수정 → 저장까지 브라우저 안에서 끝낼 수 있는 무료 썸네일 에디터입니다.

포토샵이나 별도 설치 프로그램이 필요 없습니다. 검은고딕(임팩트 스타일)·주아·도현 같은 오픈 라이선스 한글 폰트 8종이 내장되어 있어 "한글이 예쁘게 안 나오는" 해외 툴의 고질적인 문제가 없습니다. 업로드한 사진과 작업물은 서버로 전송되지 않고 전부 내 브라우저 안에서만 처리됩니다.

영상 스크린샷을 배경으로 깔고, 굵은 외곽선 텍스트를 얹고, 강조 이모지를 하나 올리는 기본 패턴이라면 1분이면 충분합니다. 만들던 썸네일은 자동으로 브라우저에 저장되고, JSON 파일로 내보내 다른 기기에서 이어서 작업할 수도 있습니다.

유튜브 썸네일 규격 요약

항목권장 값
해상도1280×720px (최소 너비 640px)
비율16:9
파일 형식JPG, PNG, GIF (정지 이미지)
파일 용량2MB 이하 (Shorts는 별도 기준)

이 페이지의 내보내기 기본값이 위 규격에 맞춰져 있어 그대로 저장해 업로드하면 됩니다. 더 자세한 플랫폼별 크기는 썸네일 권장 크기 가이드를 참고하세요. 용량이 2MB를 넘으면 JPG 형식과 품질 슬라이더로 줄일 수 있습니다.

사용법

  1. 툴바의 🎨 템플릿에서 마음에 드는 디자인을 고릅니다. (처음에 기본 템플릿이 적용되어 있어요)
  2. 텍스트를 터치/클릭해 선택한 뒤, 오른쪽 선택 요소 패널에서 문구·폰트·색·외곽선을 바꿉니다.
  3. 🖼 이미지로 영상 캡처나 사진을 올리고, 모서리 핸들로 크기·회전을 조절합니다. 드래그하면 중앙·가장자리에 자동으로 스냅됩니다.
  4. 레이어 패널에서 순서(▲▼)를 바꾸거나 필요 없는 요소를 삭제합니다.
  5. 내보내기에서 PNG 또는 JPG, 1x(1280×720)를 선택하고 이미지 저장을 누릅니다.

자주 묻는 질문

유튜브 썸네일 크기는 얼마가 좋나요?

유튜브 공식 도움말 기준 권장 해상도는 1280×720픽셀(최소 너비 640픽셀), 비율 16:9, 용량 2MB 이하입니다. 이 도구의 기본 캔버스가 정확히 1280×720이므로 그대로 저장해 업로드하면 됩니다.

만든 썸네일에 워터마크가 붙나요?

아니요. 워터마크 없이 저장되며 상업적 용도(내 채널 썸네일 등)로 자유롭게 사용할 수 있습니다. 내장 폰트도 모두 오픈 라이선스(SIL OFL 등)입니다.

업로드한 사진이 서버에 저장되나요?

아니요. 이 에디터는 서버 없이 동작하는 정적 웹앱으로, 이미지는 브라우저 메모리에서만 처리되고 외부로 전송되지 않습니다. 자동 저장도 내 브라우저(localStorage)에만 됩니다.

글자에 외곽선(테두리)은 어떻게 넣나요?

텍스트를 선택하면 나오는 패널에서 "외곽선" 색과 두께 숫자를 조절하세요. 두께를 0으로 하면 외곽선이 사라집니다. 유튜브 썸네일은 배경이 복잡한 경우가 많아 흰 글자 + 검정 외곽선 조합이 가장 잘 읽힙니다.

2MB 용량 제한에 걸리면 어떻게 하나요?

내보내기 형식을 JPG로 바꾸고 품질을 80~90 사이로 낮춰 보세요. 1280×720 JPG는 대부분 수백 KB 수준으로 저장됩니다.

모바일(아이폰)에서도 되나요?

네. 터치 드래그로 이동, 모서리 핸들로 크기 조절, 위쪽 파란 점으로 회전이 가능합니다. 저장 버튼이 동작하지 않는 일부 브라우저에서는 캔버스를 길게 눌러 이미지를 저장하세요.

이 도구의 모든 처리(이미지 편집·저장)는 사용자의 브라우저 안에서만 이루어지며, 어떤 파일이나 개인정보도 서버로 전송되지 않습니다. 업로드하는 이미지·문구의 저작권과 초상권은 사용자 본인에게 책임이 있습니다.
