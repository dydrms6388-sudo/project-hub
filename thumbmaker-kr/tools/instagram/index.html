인스타 게시물 만들기

정사각(1080×1080)과 4:5 세로(1080×1350) 프리셋을 지원합니다. 템플릿으로 시작해 문구와 색만 바꿔보세요.

인스타 게시물 만들기 — 이 도구 소개

인스타그램 피드 이미지는 정사각 1080×1080 또는 화면을 더 크게 차지하는 4:5 세로형 1080×1350이 표준입니다. 이 도구는 두 크기를 셀렉트 박스 하나로 오가며, 카드뉴스 표지·공지 이미지·이벤트 안내·감성 글귀 게시물을 브라우저에서 바로 만들 수 있는 무료 에디터입니다.

그라데이션 배경, 폴라로이드 프레임, 체크리스트 카드 같은 템플릿이 준비되어 있고, 나눔손글씨 펜·주아 같은 감성 한글 폰트를 골라 쓸 수 있습니다. 사진을 올려 프레임 위에 배치하고, 계정 아이디를 워터마크처럼 하단에 넣는 것도 텍스트 요소 하나면 됩니다.

완성본은 PNG로 저장하면 무손실 화질로, JPG로 저장하면 가벼운 용량으로 받을 수 있습니다. 인스타그램 업로드 시 앱이 다시 압축하므로 원본은 선명하게 만드는 것이 좋습니다. 2x 배율로 내보내면 확대·인쇄용으로도 쓸 수 있는 2160픽셀 이미지가 됩니다.

카드뉴스 여러 장 만들기

여러 장짜리 카드뉴스를 만들 때는 첫 장을 완성한 뒤 저장(JSON)으로 프로젝트 파일을 받아 두세요. 이후 문구만 바꿔 저장을 반복하면 같은 디자인의 시리즈를 빠르게 만들 수 있습니다. 배경·제목 위치를 통일하면 피드 그리드에서 훨씬 정돈되어 보입니다.

글자 수는 한 장에 두세 줄 이내가 좋습니다. 본문이 길다면 글씨를 줄이는 대신 장 수를 늘리는 편이 모바일에서 읽기 좋습니다.

사용법

  1. 툴바 오른쪽 크기 선택에서 정사각(1080×1080) 또는 4:5(1080×1350)를 고릅니다.
  2. 🎨 템플릿에서 디자인을 고르고, 텍스트를 눌러 문구를 내 내용으로 바꿉니다.
  3. 배경 패널에서 단색/그라데이션 색을 브랜드 색에 맞게 조절합니다.
  4. 사진이 필요하면 🖼 이미지로 올리고 드래그·핸들로 배치합니다.
  5. 내보내기에서 PNG(고화질) 또는 JPG(가벼움)를 골라 저장합니다.

자주 묻는 질문

인스타 게시물 이미지 크기는 몇으로 해야 하나요?

정사각형은 1080×1080, 세로형은 1080×1350(4:5)이 표준입니다. 세로형이 피드에서 더 큰 면적을 차지해 도달에 유리한 경우가 많습니다. 이 도구는 두 크기를 프리셋으로 제공합니다.

만든 이미지를 상업 계정에 써도 되나요?

네. 결과물에 워터마크가 없고 내장 폰트가 모두 오픈 라이선스라 상업적 이용이 가능합니다. 단, 직접 업로드한 사진·로고의 저작권은 사용자 본인에게 책임이 있습니다.

카드뉴스 여러 장을 같은 디자인으로 만들 수 있나요?

저장 버튼으로 프로젝트를 JSON 파일로 내보낸 뒤, 열기로 다시 불러와 문구만 바꾸는 방식을 추천합니다. 작업 내용은 브라우저에도 자동 저장됩니다.

업로드하면 인스타에서 화질이 떨어져 보여요.

인스타그램은 업로드 시 이미지를 다시 압축합니다. 원본을 PNG 또는 고품질 JPG(품질 90 이상)로 저장하고, 글자는 너무 가늘지 않은 폰트를 쓰면 압축 후에도 선명하게 보입니다.

사진이 서버로 올라가나요?

아니요. 모든 편집은 브라우저 안에서만 이루어지고 이미지가 외부로 전송되지 않습니다.

이 도구의 모든 처리(이미지 편집·저장)는 사용자의 브라우저 안에서만 이루어지며, 어떤 파일이나 개인정보도 서버로 전송되지 않습니다. 업로드하는 이미지·문구의 저작권과 초상권은 사용자 본인에게 책임이 있습니다.
